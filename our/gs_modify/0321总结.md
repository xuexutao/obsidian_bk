# 0321_0028_addmask：本次会话改动总结

  

> 目标：把 `masked-diff-gaussian-rasterization` 的 mask 能力**彻底集成**进 `submodules/diff-gaussian-rasterization_masked`，保证 `pip install submodules/diff-gaussian-rasterization_masked` 后能直接训练；并支持**场景内所有物体的单独高斯点云 ply 导出**；最后把 mask 进一步下沉到 CUDA rasterizer，实现“只对当前视角 mask 像素做渲染/反传”。

  

---

  

## 1. 完成了什么

  

### 1.1 Rasterizer：从“依赖外部 masked 包”到“内置 mask 能力”

  

- 将 mask 逻辑合并进 `diff_gaussian_rasterization_masked` 对应的 Python 包接口，使训练代码无需再 import `masked_diff_gaussian_rasterization`。

- `GaussianRasterizer.forward(...)` 新增可选参数 `mask` / `apply_mask_in_forward`，训练侧可按需启用。

  

### 1.2 输出：自动导出每个物体单独 `.ply`，并保留完整场景 `.ply`

  

- 在保存迭代时（`Scene.save()`）额外导出：

- 完整场景：`point_cloud/iteration_x/point_cloud.ply`

- 物体级拆分：`point_cloud/iteration_x/objects/obj_XXXX.ply`

- 这些 `obj_XXXX.ply` 是同一次训练得到的高斯子集，可与完整场景对应。

  

### 1.3 示例：以 garden 跑了一次“分割 + 重建 + 导出”

  

- 使用 `data/gs_data/garden` 生成多视角一致 SAM masks（为了加速，示例用 `images_8` 子目录，且先跑 30 张示例）。

- 用 `train.py` 对 garden 跑 1 iteration 验证产物链路：导出了 `iteration_1/objects/` 下大量 `obj_*.ply`（示例统计为 496 个）。

  

### 1.4 创新点强化：CUDA 内像素级 mask gating（只渲染 mask 像素）

  

- 之前的实现是“渲染整图 -> Python 侧/梯度侧乘 mask”，本次进一步升级为：

- 在 CUDA `renderCUDA` 的每像素线程入口处判断 `mask[pix_id]`。

- **mask=0 的像素直接跳过高斯累积与混合**，输出写为纯背景；backward 同样对 mask 外像素不做梯度传播。

- 这更贴合“只优化当前视角 mask 区域”的叙事，可作为你的创新点/贡献。

## 2. 代码改动明细（按模块）

  

### 2.1 Python：`diff_gaussian_rasterization` API 增强

  

- 文件：`submodules/diff-gaussian-rasterization_masked/diff_gaussian_rasterization/__init__.py`

- `rasterize_gaussians(..., mask=None, apply_mask_in_forward=True)`：新增参数

- **第一阶段（已完成）**：在 Python 层对 forward 输出和 backward 梯度做 mask（乘法 gating）

- **第二阶段（已完成）**：将 `mask` 作为参数真正传入 C++/CUDA 扩展（空 tensor 表示禁用）

  

### 2.2 训练渲染侧：去掉 `masked_diff_gaussian_rasterization` 依赖

  

- 文件：`gaussian_renderer/__init__.py`

- 原先会根据 `use_masked_rasterizer` 动态 import `masked_diff_gaussian_rasterization`。

- 现在统一走 `diff_gaussian_rasterization`（本仓库构建版本已内置 mask 能力）。

  

### 2.3 物体级点云导出

  

- 文件：`scene/gaussian_model.py`

- 新增 `save_ply_masked(path, mask)`：按 bool mask / idx 子集保存 ply。

  

- 文件：`scene/__init__.py`

- 在 `Scene.save()` 中新增 `_export_object_gaussians()`：

- 自动从 `<source>/<images_subdir>/<mask_dirname>/<stem>/obj_XXXX.png` 收集 obj_id

- 对每个 obj_id 选取至少一个含该 mask 的视角，基于高斯中心投影到像素后统计投票

- 生成 `objects/obj_XXXX.ply`

- 为避免因为“obj_id 在不同视角不完全一致”导致空输出，采用“votes>=1 即导出”的宽松策略。

  

### 2.4 多视角 SAM mask 生成的可观测性

  

- 文件：`utils/multiview_sam_mask.py`

- 将 `[SAM] processed ...` 打印频率提升到每张图都打印，以便长任务持续有输出（降低 watchdog/超时风险）。

  

### 2.5 CUDA 创新点：像素级 mask gating

  

> 目标：不再“按 tile/block 的方形区域对所有像素做渲染”，而是**只对 mask=1 的像素线程做渲染**。

  

- forward：

- 文件：`submodules/diff-gaussian-rasterization_masked/cuda_rasterizer/forward.cu`

- `renderCUDA` 新增 `const float* mask` 参数。

- `pix_id` 计算后：

- `masked_in = (mask==nullptr) || (mask[pix_id] > 0.5)`

- `done = (!inside) || (!masked_in)` 直接让 mask 外像素不参与高斯累积。

- 写回阶段：mask 外像素写纯背景，`n_contrib=0`，`final_T=1`。

- 同步修改声明：`cuda_rasterizer/forward.h`

  

- backward：

- 文件：`submodules/diff-gaussian-rasterization_masked/cuda_rasterizer/backward.cu`

- `renderCUDA` 新增 `const float* mask` 参数。

- `done = (!inside) || (!masked_in)`；mask 外像素的 `dL_dpixel`/`dL_invdepth` 置 0。

- 同步修改声明：`cuda_rasterizer/backward.h`

  

- C++/pybind & 调度链路：

- `submodules/diff-gaussian-rasterization_masked/rasterize_points.h/.cu`：

- forward/backward 的 C++ 扩展函数签名新增 `mask`（空 tensor 表示禁用）

- `submodules/diff-gaussian-rasterization_masked/cuda_rasterizer/rasterizer.h/.cu`：

- `Rasterizer::forward/backward` 参数链路新增 `mask` 指针，并传给 `FORWARD::render / BACKWARD::render`

## 4. 使用方式建议（你后续写创新点时）

  

1) **创新点描述**

- “mask outside pixels are skipped in CUDA rasterization (forward + backward)”，相比后处理乘 mask，更强的“只优化 mask 区域”属性。

  

2) **推荐训练参数**

- 如果做纯物体优化：`--mask_only --mask_use_masked_rasterizer --mask_object_id <id>`

- 如果做全图 + mask 辅助约束：`--mask_loss_weight > 0` 并按需启用 `--mask_use_masked_rasterizer`

  

3) **关于 obj ply 合并**

- `objects/obj_XXXX.ply` 是子集导出；“组合成完整场景”的最稳方式是使用同目录的 `point_cloud.ply`（完整场景）。
