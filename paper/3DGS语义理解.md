# 3D Gaussian Splatting（3DGS）语义理解研究综述（截至 2025 年）

  

> 关键词：3D Gaussian Splatting（3DGS）、语义分割、实例/全景分割、开放词汇（Open-Vocabulary）、视觉语言模型（VLM）、语言定位（Grounding）、可微渲染、SLAM/在线建图

  

## 摘要

  

3D Gaussian Splatting（3DGS）以显式的高斯点云（带颜色、尺度、旋转与不透明度等属性）作为场景表示，并通过可微分的 splatting/rasterization 实现高质量、实时级的新视角合成。相较于 NeRF 等隐式场，3DGS 的显式原语与高渲染效率使其天然适合作为“可交互的 3D 表征底座”，从而推动了基于 3DGS 的语义理解：包括 3D 语义/实例/全景分割、开放词汇语义检索、语言描述的 3D 目标定位与可编辑语义场等。本文围绕“如何在 3DGS 上获得稳定、可查询、可泛化的语义”这一核心问题，总结任务定义、方法脉络、监督信号与损失设计、数据集与评测协议，以及面向机器人与 AR 的应用趋势与挑战。

## 1. 背景与动机

  

### 1.1 为什么 3DGS 适合语义理解

  

从“渲染表示”走向“语义表示”，通常需要满足三类需求：

  

1. **可查询**：能够从 3D 表示中对任意视角、任意像素位置得到稳定的语义输出；

2. **可优化**：能够利用 2D/3D 监督（类别标签、mask、文本、点云标注等）通过梯度反传对表示进行更新；

3. **可交互/可扩展**：支持在线更新、局部编辑、增量融合，以及在大场景与多序列上稳定工作。

  

3DGS 在这些方面具有优势：

  

- **显式原语**：每个高斯可携带额外属性（如语义 logits、语义嵌入、实例 ID、文本对齐特征），天然支持“按点查询/聚合”。

- **高效渲染**：相较于密集体渲染或大 MLP，3DGS 的 rasterization 更接近传统图形管线，便于实时语义渲染与交互。

- **可微渲染**：在渲染过程中可对高斯参数（位置/尺度/不透明度/颜色/特征）反传，方便把 2D 监督信号“投影回 3D”。

  

### 1.2 语义理解与表示学习的耦合

  

在 3DGS 语义化过程中，“渲染质量”与“语义稳定性”往往相互制约：

  

- 渲染质量追求精细几何与纹理，可能导致高斯数量膨胀、遮挡层次复杂，从而让语义学习更不稳定。

- 语义学习需要跨视角一致性与抗噪监督，但 2D 伪标签（如自动分割/检测）存在视角不一致、边界抖动等问题。

  

因此，3DGS 语义理解研究的关键在于：**如何选择/融合监督信号，如何定义跨视角一致的语义目标，以及如何在显式原语级别进行约束与正则化**。

## 2. 3DGS 表示与可微渲染基础

  

### 2.1 基本表示

  

典型 3DGS 以一组各向异性 3D 高斯表示场景：

  

- 位置 `μ`（3D）

- 协方差/尺度与旋转（各向异性形状）

- 不透明度 `α`

- 颜色（SH 系数或视角相关外观）

  

语义扩展通常在每个高斯上再附加：

  

- **类别 logits**（用于闭集语义/全景分割）

- **语义嵌入向量**（用于开放词汇检索/语言对齐）

- **实例/物体 ID**（用于实例/跟踪）

  

### 2.2 渲染与梯度回传的语义化接口

  

语义渲染的核心是把“高斯级别语义属性”通过 alpha compositing 聚合到像素：

  

- **logits/概率的混合**：按可见性权重混合每个高斯的语义 logits 或概率，再对像素取 argmax 得到类别。

- **特征的混合**：按可见性权重混合高斯语义 embedding，得到像素级语义特征图，可用于与文本/2D 特征做对齐损失。

  

这样，2D 上的语义监督即可通过渲染链路反传到参与该像素成像的高斯，从而实现“2D→3D”的语义灌注。

## 3. 语义理解任务与问题定义

  

围绕 3DGS 的“语义理解”，常见任务可以按输出空间与监督形式分类。

  

### 3.1 闭集语义分割（Closed-set Semantic Segmentation）

  

- **目标**：给每个 3D 点/高斯或每个渲染像素预测预定义类别集合。

- **监督**：3D 标注（点云/mesh 标签）或 2D 标注（多视角语义 mask）。

- **评测**：mIoU、Acc、每类 IoU。

  

### 3.2 实例/全景分割（Instance/Panoptic）

  

- **目标**：同时输出“thing”的实例 ID 与类别，以及“stuff”的区域类别。

- **监督**：2D 实例 mask/全景标注投影，或 3D 实例标注。

- **评测**：PQ、SQ、RQ，实例 mAP，3D IoU 等。

  

### 3.3 开放词汇语义（Open-Vocabulary Semantics）

  

- **目标**：支持用户以任意文本（如“红色沙发”“灭火器”）查询，返回相关区域/高斯集合或像素 mask。

- **监督**：通常不依赖固定类别；采用 VLM（如 CLIP）对齐、2D foundation model 伪标签蒸馏或对比学习。

- **评测**：检索 mAP、文本-区域匹配准确率，或在开放词汇 3D 基准上的 mIoU。

  

### 3.4 语言定位与交互（Language Grounding & Interaction）

  

- **目标**：给定指代表达（“靠窗的那把椅子”）输出 3D 框/mask；或与场景进行可编辑交互（“把这面墙涂成蓝色”）。

- **关键**：语义不仅要“分类”，还要“可指代、可组合、可编辑”。

## 4. 方法谱系：在 3DGS 上“长出语义”

  

本节给出一条从“简单投影”到“联合优化与开放词汇”的方法谱系。实际工作常将多类策略组合。

  

### 4.1 2D→3D 的语义提升：投影/反投影与标签融合

  

**基本思想**：利用多视角的 2D 语义结果（人工标注或自动模型输出），通过相机投影把像素标签关联到被渲染/可见的高斯，再在高斯上做投票或概率融合。

  

常见做法：

  

- **多视角投票**：对每个高斯累计来自不同视角的类别分布并归一化。

- **置信度加权**：按 2D 模型置信度、视角入射角、深度一致性等对标签贡献加权。

- **时空一致性正则**：对相邻高斯或局部邻域施加平滑（graph/CRF/TV）以减少抖动。

  

优点：实现简单、训练成本低。缺点：强依赖 2D 伪标签质量，且跨视角不一致会被“固化”。

  

### 4.2 显式语义参数化：每个高斯携带语义 logits 或 embedding

  

**基本思想**：把语义作为可学习参数直接存到高斯上，并通过“语义渲染器”得到像素级语义输出，与监督信号计算损失。

  

两类主流表征：

  

- **类别 logits（闭集）**：每个高斯一个 `C` 维向量；渲染得到像素 logits，做交叉熵/软标签 KL。

- **语义 embedding（开放词汇）**：每个高斯一个 `D` 维向量；渲染得到像素特征图，与 CLIP 图像特征或 2D foundation 特征对齐。

  

关键点在于：

  

- **可见性权重**：语义混合应使用与颜色渲染一致的可见性/透射率权重，以保证语义与外观对齐。

- **遮挡与多层结构**：前景/背景高斯混合会造成语义“污染”，常需引入深度一致性或分层监督缓解。

  

### 4.3 联合优化：外观-几何-语义的多任务学习

  

**基本思想**：在 3DGS 的 photometric loss（重建）之外加入语义损失，实现联合优化。典型组合：

  

- 重建：L1/SSIM（颜色）

- 几何：深度一致性、法线一致性、稀疏 SfM 点约束

- 语义：2D mask/类别监督、特征对齐、跨视角一致性

  

联合优化的收益：

  

- 语义监督可反过来约束几何（例如物体边界对齐），减少漂浮点。

- 几何/深度一致性可提升语义投影的可靠性，减少跨视角冲突。

  

风险：

  

- 语义损失过强可能牺牲渲染质量；需要损失权重调度与分辨率/尺度策略。

  

### 4.4 开放词汇与语言对齐：VLM 蒸馏与文本查询

  

**基本思想**：借助 CLIP 等 VLM 的跨模态对齐能力，把“语言空间”的语义注入到 3DGS。常见路线：

  

- **图像特征蒸馏**：用 VLM 提取 2D 图像/patch 特征，要求渲染出的像素特征与之匹配（L2/余弦/对比损失）。

- **mask 引导的语义对齐**：用 SAM 等得到候选 mask，再对 mask 区域与文本提示进行 CLIP 相似度打分，把高分区域作为伪监督。

- **文本查询渲染**：在推理时，将文本编码为向量，与渲染出的像素/高斯 embedding 做相似度，输出热力图或阈值化 mask。

  

开放词汇的难点：

  

- 文本与视觉概念存在歧义（同义词、属性组合）；

- 2D VLM 特征对 3D 遮挡与尺度变化更敏感，需要跨视角一致性约束；

- 语义 embedding 维度与高斯数量带来显存与带宽压力，需要压缩/量化策略。

  

### 4.5 在线/增量语义：与 SLAM/建图融合（面向机器人）

  

当 3DGS 用于在线建图时，语义学习需要支持：

  

- **增量融合**：新帧到来时更新已有高斯或新增高斯，同时保持旧语义不灾难遗忘。

- **动态物体处理**：把动态目标从静态背景中分离，分别建模语义与运动。

- **实时性约束**：语义渲染/更新与跟踪/建图共享算力，需要轻量损失与稀疏更新。

  

常见思路是将语义模块设计为可插拔：离线阶段构建高质量语义高斯，在线阶段做轻量增量与置信度更新。

## 5. 训练与实现要点（工程与损失）

  

### 5.1 语义渲染器：从高斯到像素

  

为了兼顾稳定性与可训练性，语义渲染一般遵循：

  

- 与颜色渲染共享排序与可见性权重（保证对齐）。

- 对 logits/embedding 做线性混合，必要时在像素端再做归一化。

  

实践中常用技巧：

  

- **分辨率策略**：语义损失在较低分辨率计算，减少噪声与算力。

- **边界鲁棒**：对边界像素用软标签/标签平滑，降低伪标签边界抖动的影响。

  

### 5.2 监督来源与噪声建模

  

语义监督可来自：

  

- 人工标注（2D/3D）

- 2D foundation 模型伪标签（分割/检测/开放词汇）

- 多模态对齐（CLIP 等）

  

噪声处理策略：

  

- 置信度阈值与温度缩放

- 多视角一致性过滤（只保留跨视角一致的区域）

- 自训练/迭代重标注（用当前 3D 一致语义反哺 2D）

  

### 5.3 正则化与可扩展性

  

- **空间平滑**：邻域一致性（kNN 图）或 TV 正则，减少“盐胡椒噪声”。

- **类别平衡**：长尾类别可用 re-weighting 或 focal loss。

- **压缩与蒸馏**：embedding 量化、低秩分解、按需激活（只对可见高斯更新）。

## 6. 数据集、评测指标与实验协议

  

### 6.1 常用数据集（示例）

  

| 场景 | 数据集（代表） | 典型用途 |

|---|---|---|

| 室内 RGB-D | ScanNet、Replica、TUM RGB-D、Matterport3D | 3D 语义/实例/全景、重建与定位 |

| 室外街景 | KITTI、SemanticKITTI、nuScenes、Waymo | 大尺度语义、动态目标、长期一致性 |

| 合成 | Hypersim 等 | 可控光照/标注完备、泛化测试 |

  

说明：3DGS 常通过多视角图像 + 相机位姿（SfM/SLAM）构建；若需要绝对尺度或稠密深度，常引入 RGB-D 或深度估计。

  

### 6.2 评测指标与协议建议

  

- **语义分割**：mIoU（2D/3D），同时报告每类 IoU 与总体 Acc。

- **实例/全景**：PQ（及 SQ/RQ），实例 mAP（按 IoU 阈值）。

- **开放词汇**：文本-区域检索 mAP、Top-K 命中率；必要时区分“同义词鲁棒性”。

- **效率**：FPS、显存占用、高斯数量、训练/更新速度（对机器人场景尤其关键）。

  

协议上建议同时报告：

  

- **按视角评测**（渲染输出的 2D mask/标签）与 **按 3D 原语评测**（高斯/点云标签），以避免只在渲染端“看起来好”。

## 7. 典型应用场景

  

- **语义可视化与检索**：在实时渲染中叠加类别/相似度热力图，用文本检索场景内容。

- **交互式编辑**：基于语义 mask 选中区域，进行材质/颜色替换、局部重渲染或内容编辑。

- **机器人导航与操作**：把 3DGS 作为地图底座，语义层提供可通行区域、目标物体定位与抓取候选。

- **AR/VR 场景理解**：实时语义标注提升遮挡、交互与物体持久化的可靠性。

## 8. 挑战与未来趋势

  

### 8.1 关键挑战

  

- **跨视角语义一致性**：2D 伪标签抖动会在 3D 中累积并放大。

- **遮挡与薄结构**：透明/反射/细薄结构导致语义混合污染。

- **动态与长期建图**：在线更新带来漂移与灾难遗忘，动态目标需要解耦表示。

- **开放世界与长尾**：开放词汇检索需要处理同义词、属性组合与领域偏移。

- **规模与存储**：高斯数量与语义 embedding 带来显存/带宽瓶颈，需要压缩与层次化表示。

  

### 8.2 未来趋势（值得关注）

  

- **“渲染-理解-编辑”一体化**：语义与外观共享原语并可互相约束，形成可编辑的 3D 场。

- **多模态监督融合**：结合 VLM、深度估计、SAM 类分割、3D 预训练模型，提高弱监督鲁棒性。

- **面向具身智能的在线语义地图**：把 3DGS 的实时渲染与 SLAM 的增量更新结合，支持长期任务与交互。

- **压缩与端侧部署**：语义 embedding 量化、分块加载、可见区域优先更新，以支持移动端/AR 设备。
