# PAD：联合去噪过程的视觉策略学习

## 基本信息

- **作者**：Yanjiang Guo*、Yucheng Hu*、Jianke Zhang、Yen-Jen Wang、Xiaoyu Chen、Chaochao Lu、Jianyu Chen（* 共同一作）
- **机构**：清华大学交叉信息研究院（IIIS）、上海人工智能实验室、上海期智研究院
- **发表**：NeurIPS 2024（arXiv 2411.18179）
- **原文 PDF**：<https://arxiv.org/pdf/2411.18179>

## 一句话结论

PAD 把机器人动作建模成扩散去噪过程中的一种「虚拟观测」，让模型在同一个联合去噪过程里同时生成「未来图像」和「通向未来所需的动作」，从而把逆动力学隐式编码进扩散模型。相比 UniPi / SuSIE 那种「先预测整段视频、再反推动作」的两段式路线，联合去噪让视频预测与动作决策互相校正，在 MetaWorld 上相对提升 +26.3%、真机 +28.0%。

---

## 1. 研究背景与问题定义

### 1.1 问题定位

机器人策略学习里有两类长期纠缠的目标：一是「预测世界会怎样」的视觉生成问题，二是「我该怎么做」的动作决策问题。2024 年前后的主流做法是把两者拆开串行处理——先用视频扩散模型预测未来画面（UniPi、SuSIE、GR-1），再训练一个逆动力学模型从「当前帧 + 预测未来帧」反推动作。这条链路的症结在于：逆动力学模型被当成一个独立的后置组件训练，视频预测阶段的误差会一路放大到动作输出，且动作信号在视频生成阶段完全没有被利用。

PAD 的出发点是一个更简洁的直觉：**动作本身就是连接「现在」与「未来」的桥梁**，把它和未来图像放进同一个去噪过程，模型就能在生成未来的同时「顺便」把动作求出来，而不是生成完未来之后再单独反推。

### 1.2 与 VPP / UniPi 的关系

本文是受访者郭彦江（也是 VPP 的共同一作）在「世界动作模型」这条线上的另一代表作，与 VPP 形成镜像关系：

- **UniPi / SuSIE**：视频生成在前、逆动力学在后，两阶段解耦，逆动力学是「看未来猜动作」的后处理；
- **VPP**：干脆不做完整未来预测，只用视频模型内部表征（一步前向）作为视觉编码器，动作由扩散策略直接学；
- **PAD**：坚持「联合预测未来 + 动作」，但把两者放进同一扩散过程，让逆动力学成为去噪的隐式副产品。

石麻笔记 EP06 专访中受访者把这两条路线（「视频模型当 encoder」vs「联合预测 video+action」）并列为世界动作模型的两个分支，PAD 正是后者的代表。

### 1.3 核心贡献

1. 提出「动作即虚拟观测」的联合去噪范式，统一了图像预测与动作预测；
2. 消解了传统两段式路线中逆动力学模型作为独立组件的必要性，动作由扩散模型端到端输出；
3. 在仿真（MetaWorld）与真机（机械臂）上验证联合去噪优于「先预测再反推」的串行基线。

## 2. 核心方法

### 2.1 联合去噪的建模思路

扩散模型的标准设定是从高斯噪声 $\mathbf{x}_T \sim \mathcal{N}(0, \mathbf{I})$ 逐步去噪回干净数据 $\mathbf{x}_0$。PAD 的关键改造是把「动作」也纳入这条去噪链：把未来图像 $\mathbf{x}_0$（视频帧序列）与动作序列 $\mathbf{a}_0$ 视作一个联合的干净样本，去噪网络在每个时间步同时输出两者的估计。

用符号表达，联合目标可概括为在去噪过程中同时拟合图像与动作：

$$\mathcal{L} = \mathbb{E}_{\mathbf{x}_0, \mathbf{a}_0, \boldsymbol{\epsilon}, t}\left[\left\| \hat{\mathbf{x}}_\theta(\mathbf{x}_t, t, c) - \mathbf{x}_0 \right\|^2 + \lambda \left\| \hat{\mathbf{a}}_\theta(\mathbf{x}_t, t, c) - \mathbf{a}_0 \right\|^2 \right]$$

其中 $c$ 是当前观测与语言指令的条件，$\hat{\mathbf{x}}_\theta$ 与 $\hat{\mathbf{a}}_\theta$ 由同一骨干网络的两个输出头给出，$\lambda$ 平衡图像重建与动作回归。

### 2.2 逆动力学的隐式化

传统做法里，动作 $a_t$ 由显式的逆动力学函数 $f^{-1}(s_t, s_{t+1})$ 从「当前状态 + 未来状态」反推。PAD 不再显式构造这个函数，而是让去噪网络在「预测 $s_{t+1}$ 的同时」直接输出 $a_t$。由于两者共享同一潜变量与梯度，网络在训练中被迫学会一种自洽的耦合：它生成的未来必须能被它生成的动作所解释。这种「隐式逆动力学」避免了显式逆动力学模型对标注动作质量敏感、以及预测误差逐级放大的问题。

### 2.3 训练与推理流程

- **训练**：给定当前观测 + 语言指令作为条件，对「未来图像 + 动作」联合加噪，网络端到端去噪；
- **推理**：从噪声出发，多步去噪后同时得到未来图像与动作 chunk，直接执行动作部分；图像预测仅作为训练期的约束与调试可视化，不参与实时控制。

## 3. 实验与结果

### 3.1 主要定量结果

- **MetaWorld**：联合去噪策略相对两段式串行基线相对提升 **+26.3%**，验证了「动作参与去噪」对策略质量的正向作用；
- **真机机械臂**：成功率相对提升 **+28.0%**，说明联合建模的收益在真实硬件上依然成立，而非仅限仿真。

### 3.2 关键结论

论文的核心实证贡献是消解了「先预测视频再反推动作」这条长期主流链路的合理性：只要把动作塞进去噪过程，就不需要单独训练逆动力学模型，而且端到端耦合带来的动作一致性比显式逆动力学更稳。

---

## 4. 局限与评价

1. **与 VPP 的路线之争尚未定论**：PAD 的联合去噪在 MetaWorld 上 +26.3%，但 VPP 的「一步前向表征」在 CALVIN 长程任务上同样领先（Avg. Len 4.33）。两条路线各有所长，前者在「动作与预测强耦合」的任务上更稳，后者在「数据有限、追求推理速度」时占优；
2. **联合去噪仍需多步采样**：相比 VPP 的一步前向（<160 ms 闭环），PAD 的多步去噪推理成本更高，实时性上的取舍需要结合具体硬件权衡；
3. **未充分展示多模态未来**：论文重点在动作质量，对「输出多种可能未来」的多模态建模着墨有限；
4. **数据与算力门槛**：依赖预训练视频扩散模型的权重，闭源基础模型（如 Sora 类）无法直接复用该路径。
