# π星0.6：从经验与纠正中学习的 VLA

## 基本信息

- **正式名称**：$\pi^*_{0.6}$: a VLA That Learns From Experience
- **作者**：Physical Intelligence 团队（Ali Amin、Raichelle Aniceto、Ashwin Balakrishna、Kevin Black、Chelsea Finn、Sergey Levine、Liyiming Ke 等）
- **发表**：arXiv 2511.14759v2（2025）
- **项目页**：<https://pi.website/blog/pistar06>
- **原文 PDF**：<https://arxiv.org/pdf/2511.14759>
- **方法名**：RECAP（RL with Experience and Corrections via Advantage-conditioned Policies）
- **系列位置**：π0.5 → π0.6 → 可做 RL 的 π星0.6；后续 [[RL Token - 基于VLA表征的高效在线强化学习]] 选择冻结 π0.6、只训练轻量 actor-critic 的另一条在线 RL 路线

## 一句话结论

RECAP 用一个语言条件的分布式 value function 把演示、自主 rollout 和人类在线纠正统一换算成 advantage，再把 advantage 二值化为 VLA 的条件 token，以普通监督/flow-matching 目标训练整套 $\pi^*_{0.6}$；这种“迭代离线 RL”避免直接对 flow policy 求难处理的 log-prob policy gradient，在叠衣、纸盒组装和专业咖啡机任务上把部分最难任务的吞吐提高到 2 倍以上、失败率约减半，并可在少量轮次中消除特定失败模式。

## 1. 研究背景与问题定义

### 1.1 为什么通用 VLA 仍需要真实经验

大规模 VLA 能从跨机器人演示中学到通用技能，却受制于演示分布：遥操作本身可能慢、存在不一致，且很难覆盖策略部署后真正会犯的错误。对于叠衣、倒液体、折纸盒等长程任务，少量局部错误会在数分钟内累积；只做 imitation learning 等于要求人在采数据时预先枚举所有失败与恢复。

论文的目标不是从零做单任务 RL，而是让已经具备广泛能力的 foundation VLA 在真实部署中继续学习：利用自主执行的成功/失败结果、旧策略数据、示范和人类介入纠正，同时保持大模型训练的稳定与可扩展性。

### 1.2 直接 VLA-RL 的三道障碍

1. **flow/diffusion policy 的 policy gradient 不自然**：动作通过多步连续生成得到，精确 log-likelihood 难算，PPO/REINFORCE 在大模型上既昂贵又容易不稳。
2. **数据高度异构且 off-policy**：训练集混合人类专家、当前策略、历史策略和干预片段；只用最新 on-policy 数据浪费真实机器人经验。
3. **奖励稀疏且任务很长**：一次咖啡制作、纸盒组装或衣物折叠可持续数分钟，只看 episode 成败难以判断哪一步是进展、哪一步是错误。

### 1.3 核心贡献

1. 提出 RECAP：数据收集 → 分布式 value function → advantage-conditioned policy extraction 的可迭代 VLA-RL recipe。
2. 将 advantage 变成二值条件 $I_t$，用监督学习同时拟合行为分布和“更优动作”条件分布，兼容 continuous flow action expert。
3. 从数万小时跨任务、跨本体演示做 offline RL 预训练，得到可在下游继续通过真实经验提升的 $\pi^*_{0.6}$。
4. 在真实长程、接触丰富、含可变形物体和液体的任务上验证吞吐、成功率、多轮改进和定向失败模式移除。

## 2. 任务定义与输入输出

### 2.1 强化学习形式化

策略 $\pi(a_t\mid o_t,\ell)$ 接收视觉/本体观测 $o_t$ 和语言任务 $\ell$，输出动作。轨迹为 $\tau=(o_0,a_0,\ldots,o_T)$，无折扣回报

$$R(\tau)=\sum_{t=0}^{T}r_t,\qquad
J(\pi)=\mathbb E_{\tau\sim\rho_\pi}[R(\tau)].$$

value function 是 $V^\pi(o_t,\ell)=\mathbb E[\sum_{t'=t}^{T}r_{t'}]$。RECAP 使用 $N$-step advantage：

$$A^\pi(o_t,a_t,\ell)=
\mathbb E\left[\sum_{t'=t}^{t+N-1}r_{t'}+V^\pi(o_{t+N},\ell)\right]-V^\pi(o_t,\ell).$$

它衡量“执行这个动作后，后续进展是否优于当前状态价值所预期”。论文把任务进度 value 归一化到 $(-1,0)$：0 对应完成，向 0 上升表示更接近成功。

### 2.2 数据输入与训练输出

- **数据**：通用演示 $D_{\mathrm{demo}}$；下游高质量示范；自主 rollout 及 episode outcome；执行过程中专家 teleoperation intervention。
- **value 输出**：给定图像和语言，输出 $B=201$ 个离散 value bins 的分布 $p_\phi(V\mid o_t,\ell)$。
- **policy 输入**：多相机图像、语言/子任务 prompt、metadata、本体状态，以及二值 advantage indicator $I_t$。
- **policy 输出**：VLA 的离散高层/文本输出与 flow-matching 连续动作 chunk。

## 3. 核心方法

### 3.1 RECAP 总体循环

![](assets/π星0.6%20-%20从经验与纠正中学习的VLA/figures/01-teaser.png)

> **图 1（原论文 Figure 1，第 1 页）：RECAP 全流程。** 左侧的多机器人演示、子任务文本和 web 多模态数据预训练 $\pi^*_{0.6}$ 与 value function；右侧在纸盒、咖啡和多样衣物任务上收集 rollout、奖励标签与干预，再迭代更新 value 和 advantage-conditioned VLA。来源：<https://arxiv.org/abs/2511.14759>

RECAP 每轮包含三步：

1. **收集经验**：执行当前策略，给 episode 标注任务结果；策略犯错时可由人接管，留下纠正动作。
2. **拟合 value function**：用至今所有数据估计行为混合策略 $\pi_{\mathrm{ref}}$ 的进度/成功价值。
3. **advantage-conditioned policy extraction**：计算数据中各动作 advantage，把“是否优于阈值”作为额外条件训练 VLA；部署时要求高 advantage 条件，抽出更优策略。

预训练阶段只做第 2、3 步，把海量演示转换成 offline RL 监督；下游阶段加入第 1 步并迭代。专用任务模型从预训练权重微调；论文也说明最终 generalist 可从头结合各 specialist 数据训练。

### 3.2 分布式 value function

RECAP 不直接回归一个标量，而是预测离散 value 分布：

$$p_\phi(V\mid o_t,\ell)\in\Delta^B,\qquad B=201.$$

对轨迹中时刻 $t$ 的 Monte Carlo return $R_t(\tau)=\sum_{t'=t}^{T}r_{t'}$，离散化为 $R_t^B$，最小化交叉熵：

$$\min_\phi\;
\mathbb E_{\tau\in D}
\left[\sum_{o_t\in\tau}
H\big(R_t^B(\tau),p_\phi(V\mid o_t,\ell)\big)
\right].$$

连续值由各 bin 的期望恢复：

$$V^{\pi_{\mathrm{ref}}}(o_t,\ell)=
\sum_{b=1}^{B}p_\phi(V=b\mid o_t,\ell)v(b).$$

预训练时 $D$ 主要是人类演示，value 学的是多任务、多 metadata 条件下的预期进展；迭代后 $D$ 混合演示和历代策略数据，value 相应变为混合行为策略的估计。作者承认这不是更经典的 off-policy Q estimator，但实际更稳定、容易扩展到大规模视频-语言 backbone。

### 3.3 Advantage-conditioned policy extraction

正则化 RL 的闭式改进策略可写成

$$\widehat\pi(a\mid o,\ell)\propto
\pi_{\mathrm{ref}}(a\mid o,\ell)
\,p\big(I\mid A^{\pi_{\mathrm{ref}}}(o,a,\ell)\big)^\beta.$$

利用 Bayes rule：

$$\widehat\pi(a\mid o,\ell)\propto
\pi_{\mathrm{ref}}(a\mid o,\ell)
\left(
\frac{\pi_{\mathrm{ref}}(a\mid I,o,\ell)}
{\pi_{\mathrm{ref}}(a\mid o,\ell)}
\right)^\beta.$$

当 $\beta=1$ 时，目标恰好是 $\pi_{\mathrm{ref}}(a\mid I,o,\ell)$。因此无需显式计算 flow policy 的 log-prob policy gradient，只需训练同一模型既能表示无条件行为分布，也能表示“给定改进指示”的动作分布。这与 classifier-free guidance 的条件/无条件联合建模相似。

RECAP 用任务相关阈值二值化 advantage：

$$I_t=\mathbf1\left[A^{\pi_{\mathrm{ref}}}(o_t,a_t,\ell)>\epsilon_\ell\right],$$

并优化

$$\min_\theta\;
\mathbb E_{D_{\pi_{\mathrm{ref}}}}
\left[-\log\pi_\theta(a_t\mid o_t,\ell)
-\alpha\log\pi_\theta(a_t\mid I_t,o_t,\ell)
\right].$$

实际 $\pi^*_{0.6}$ 同时有离散输出和 flow-matching 连续动作，因此第一/第二项分别落到 token likelihood 与 continuous flow loss。阈值 $\epsilon_\ell$ 比固定 $0$ + 大 CFG 权重更可控：过大的 CFG 会把动作推向分布支持边角并导致激进行为，而且无法同等作用于自回归分支。

### 3.4 人类纠正如何进入同一目标

对于 intervention 期间由专家提供的动作，作者直接强制 $I_t=\mathrm{True}$。这等价于假设专家接管动作优于当前策略犯错时的动作，使少量纠正不必单独设计 imitation loss，就能与自主成功/失败数据一起进入 advantage-conditioned 训练。

这种处理的优点是数据统一，风险是专家也可能有噪声；论文没有建模纠正质量或介入选择偏差。工程上最好记录介入前后状态、操作者身份与置信度，而不是无条件把所有纠正当最优。

### 3.5 $\pi^*_{0.6}$ 与 value 架构

![](assets/π星0.6%20-%20从经验与纠正中学习的VLA/figures/02-architecture.png)

> **图 2（原论文 Figure 3，第 4 页）：$\pi^*_{0.6}$ 与 value function。** 策略使用 SigLIP 400M + Gemma 4B 的 VLM backbone 和约 860M flow action expert；独立 value function 使用 SigLIP 400M + Gemma 270M 及 value head。value 计算 $A(o,a)=r_{t:t+N}+V(o_{t+N})-V(o_t)$，二值化后作为策略 metadata 条件。来源：<https://arxiv.org/abs/2511.14759>

策略遵循 Knowledge Insulation（KI）训练 recipe：VLM backbone 保留 next-token prediction 等多来源预训练，flow action expert 通过 stop-gradient 隔离，降低动作训练对通用视觉语言知识的破坏。Value function 采用更小的 VLM，但仍接收多相机视觉、语言和 metadata，适合多任务共享。

### 3.6 完整算法

先在 $D_{\mathrm{demo}}$ 上训练 $V_{\mathrm{pre}}$，再用该 value 训练 $\pi_{\mathrm{pre}}$。对任务 $\ell$，以示范初始化 $D_\ell$，从预训练权重得到 $V_\ell^0,\pi_\ell^0$；每轮 $k$ 用 $\pi_\ell^{k-1}$ 收集数据并加入 $D_\ell$，然后**从预训练初始化**重新/继续拟合 $V_\ell^k$ 和 $\pi_\ell^k$。反复使用所有历史数据使方法更接近 iterated offline RL，而非高方差 on-policy 更新。

## 4. 数据、在线收集与实验设置

### 4.1 预训练与下游数据

预训练覆盖**数万小时**、大量任务和多种机器人本体的 demonstration，并混合子任务语言、metadata 与 web 多模态数据。论文没有公开逐来源小时数和混合比例，因此无法完整重建 data recipe。

下游任务为：

- **Laundry（T-shirt/shorts）**：从篮中取衣、展平、折叠并堆放，200 秒；
- **Diverse laundry**：11 类衣物，定量重点测困难的纽扣衬衫，500 秒；
- **Targeted failure removal**：固定橙色 T-shirt，严格要求衣领朝上且居中，200 秒；
- **Double-shot espresso**：取手柄、磨豆、压粉、锁入、放杯、萃取并上饮品，200 秒；
- **Box assembly**：扁平纸板折箱、贴标、放入周转箱，600 秒。

### 4.2 在线收集规模

多轮实验中，普通叠衣每轮在 4 台机器人上收集 **300 条轨迹**，只用自主评测、无 intervention，用于隔离纯 RL 改进；纸盒每轮收集 **600 条自主轨迹 + 360 条 intervention 轨迹**。定向失败移除做 2 轮，每轮 **600 条轨迹**，同样无新增示范或干预。

论文还报告长时间运行案例：咖啡连续 **13 小时**、新家庭环境多样衣物折叠超过 **2 小时**不中断，纸盒策略用于真实包装工厂。这些是系统稳健性展示，不等价于受控随机试验，但补充了长时间部署证据。

### 4.3 Baseline 与指标

Baseline 包括 supervised π0.5、supervised π0.6、只做 RL 预训练的 $\pi^*_{0.6}$、offline RL pretrain + downstream SFT、最终 RECAP；policy extraction 另比较 AWR 与 PPO/DPPO/FPO 风格实现。指标为成功率与吞吐（每小时成功任务数），后者同时惩罚失败和缓慢执行。

PPO 为适应 off-policy 数据使用较小 trust-region $\eta=0.01$；AWR 按 value advantage 加权回归。为控制比较，二者使用与最终 RECAP 相同的 on-robot 数据，这实际上让 baseline 看到了由 RECAP 策略收集的较好数据。

## 5. 实验结果

### 5.1 主要定量结论

最终 $\pi^*_{0.6}$ 在所有任务上都优于 supervised π0.6、仅 RL 预训练模型和 offline RL + SFT。**Diverse laundry 与 espresso 的吞吐从加入 on-robot 数据后提高到 2 倍以上，失败率约降低 2 倍**。除 diverse laundry 外，最终模型成功率均达到 **90%+**；较简单的 T-shirt/shorts 任务在 SFT 后成功率已接近上限，但 RECAP 仍显著缩短完成时间、提高吞吐。

纸盒拆成拾取纸板、折箱、贴标、入箱四阶段，最终策略每一阶段都更高；剩余失败多数是 600 秒时限用尽，而非立即灾难性失败。这说明 RECAP 同时改善速度与恢复效率，而不只是某个二元终点动作。

### 5.2 多轮改进

叠衣经过两轮自主数据后总吞吐提高约 **50%**：第一轮成功率已超过 **90%**，第二轮主要继续提速。纸盒第一轮可能短暂下降，但第二轮后吞吐约 **2×**；最终折箱与贴标阶段都约 **90% 成功率**。这印证长程任务需要更大经验量，且迭代并非单调——value 与数据混合可能在早期产生分布偏移。

### 5.3 Policy extraction 对比

在 T-shirt/shorts 上，AWR 和 PPO 都能得到合理结果，但明显低于 RECAP，且难以超越 offline RL + SFT 起点。PPO 的小 trust region 保住稳定却限制改进；AWR 能保持一定成功率，但策略更慢、吞吐低。Advantage conditioning 的优势在于：不丢弃低 advantage 数据，而是让模型在条件变量下同时解释好/坏行为；推理时选择“改进”条件即可抽取更优分布。

### 5.4 定向移除失败模式

在“橙色 T-shirt 衣领必须朝上且居中”的对抗初始条件中，baseline 经常用错误朝向完成看似合理的折叠。RECAP 在无 intervention、无额外 demonstration 的情况下做两轮、每轮 600 条轨迹，最终达到 **97% 成功率**且速度较高。这是本文最清晰的因果式证据：稀疏任务判据可以通过 advantage 条件改变策略偏好，而不是仅复制人类示范。

### 5.5 Value function 定性证据

![](assets/π星0.6%20-%20从经验与纠正中学习的VLA/figures/03-results.png)

> **图 3（原论文 Figure 4，第 5 页）：value function 对成功与失败轨迹的逐时刻判断。** 叠衣时机械臂甩起并弄皱已折衣物，value 明显下降，恢复折叠后回升；开冰箱任务在成功开门时上升、打翻滤水壶时下降。说明 value 不只记终点标签，也学到中间进展和错误。来源：<https://arxiv.org/abs/2511.14759>

这张图支持用 $V(o_{t+N})-V(o_t)$ 做 advantage 的合理性，但仍只是少量定性样本；更严格的校准、OOD 环境和错误归因指标未系统报告。

### 5.6 结果是否支撑主张

任务难度、真实持续时间和 baseline 覆盖都很强，特别是 AWR/PPO 与定向失败移除实验。不过主论文的 Figure 7/8 以柱图呈现，缺少完整逐项数值表、样本数和显著性检验；“2×”与“90%+”是可精确引用的正文结论，不能从图中虚构更多小数。系统高度依赖未公开的大规模数据、模型和机器人运维，外部可复现性弱。

## 6. 与相关工作及系列关系

### 6.1 π 系列演进

- **π0**：确立 VLM + flow action expert 的通用连续动作 VLA。
- **π0.5**：强调开放世界泛化与异构数据配方。
- **π0.6**：更大 backbone、更多条件和 KI 训练 recipe。
- **π星0.6**：在 π0.6 上加入 advantage indicator，并配套 value function 与 RECAP，使模型可从奖励、rollout 和纠正继续提升。

星号不是简单版本升级，而是“可做 advantage-conditioned RL 的 π0.6 分支”。

### 6.2 与 DAgger/AWR/PPO 的关系

RECAP 用 intervention 类似 DAgger 收集策略访问状态下的专家纠正，但还利用未介入的成功/失败 rollout；相较 AWR，它不会将低 advantage 数据直接降权丢弃，而是用条件建模保留全部数据；相较 PPO，它不要求 flow model 的精确 likelihood 或纯 on-policy buffer，更适合数万小时离线数据和大 VLA。

### 6.3 与 RTC 系列的关系

RTC/Training-Time RTC 处理“策略推理慢时如何连续执行”，RECAP 处理“执行后如何从成败与纠正中改进参数”。RECAP 的数据收集 rollout 可使用 RTC 提高吞吐，但执行协议变化也会改变行为分布与 value，联合系统应在同一 runtime 下收集与训练。

### 6.4 与 RL Token 的关系

RL Token 后续选择冻结 VLA，把其内部特征压成 2048 维 token，只训练小 actor-critic，并以 VLA 动作作正则锚点。RECAP 是**全模型、离线式、长程多阶段、重数据**路线；RL Token 是**冻结骨干、在线 off-policy、关键精密阶段、少数据**路线。两者可形成分层配方：RECAP 先获得强通用/任务 VLA，RLT 再在现场用几十分钟到数小时做局部精调。

## 7. 局限与批判性评价

1. **奖励与介入依赖人**：episode outcome、干预和部分评价都需人工；系统尚不是自主 self-improvement。
2. **value 是混合行为策略的 Monte Carlo 估计**：数据来自人和多代策略，$V^{\pi_{\mathrm{ref}}}$ 的含义随数据权重变化；不是严格 off-policy Q，advantage 可能偏置。
3. **Markov 假设不完全成立**：论文形式化把观测当状态，但遮挡、衣物内部形态和长程任务进度需要记忆；单帧 value 可能混淆不可见历史。
4. **干预强制正标签过强**：专家纠正也可能迟滞或次优，且介入位置有选择偏差。
5. **阈值依赖任务**：$\epsilon_\ell$ 控制最优性与行为正则化，需要任务级选择；大量新任务如何自动设定未解决。
6. **巨大的不可复现先验**：数万小时数据、约 4B 级 VLM、860M action expert、多机器人并行与运维体系都未公开。
7. **灾难性遗忘与跨任务权衡**：KI 降低知识干扰，但多轮 specialist RL 后是否保持通用能力，主实验没有完整回归评测。
8. **实验数值透明度有限**：正文给出倍数和阈值性结论，但缺少完整表格、种子和成本明细。

## 8. 复现与实践建议

### 8.1 最小算法复现

先在仿真或现有 flow policy 上实现 RECAP 核心，而非直接复刻 π0.6：收集 demonstration + policy rollout；训练 201-bin distributional value；用 $N$-step value difference 生成 advantage；按任务阈值二值化；给 policy 加一个 indicator embedding；同时训练无条件和条件 flow loss；迭代两轮比较 success/throughput。

### 8.2 数据与评测要求

- 保留每条轨迹的行为策略版本、reward、终止原因、intervention 区间和 task metadata。
- 训练/验证按 episode 和环境划分，避免相邻帧泄漏。
- 除成功率外必须报告吞吐、时限失败、恢复次数和介入分钟数。
- 校准 value：测试 predicted value 与实际 return、错误发生前后的敏感性及 OOD 场景。
- 做全任务回归，确认 targeted improvement 没有损害预训练技能。

### 8.3 成本评估

算法级复现为中高成本；论文级复现极高。至少需要多相机双臂平台、长程任务工装、数百到上千条真机轨迹、人工 reward/intervention、数十亿参数训练和持续机器人运维。论文未披露完整训练超参数、数据混合比例、权重或代码，严格复现暂不可行；可以复现思想与小规模对照，而不能声称复刻 $\pi^*_{0.6}$。

## 9. 个人启发与后续问题

RECAP 最有价值的思想是把“RL policy extraction”降维为“条件生成”：大生成模型不必直接接受高方差 policy gradient，只要学会同时描述行为分布和高 advantage 子分布。这一范式可能扩展到视频 world-action model、语言代理轨迹和多模态生成。后续问题包括：是否能用不确定性校准 value；是否能学习连续 advantage 而非二值阈值；是否能自动评价 intervention 质量；如何联合 recurrent state 处理长程部分可观测性；以及能否把 RLT 的轻量在线更新作为 RECAP 每轮全模型训练之前的快速适配层。
