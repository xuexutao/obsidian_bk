# UP-VLA：统一理解与预测的具身模型

## 基本信息

- **作者**：Jianke Zhang*、Yanjiang Guo*、Yucheng Hu*、Xiaoyu Chen、Xiang Zhu、Jianyu Chen（* 共同一作）
- **机构**：清华大学交叉信息研究院（IIIS）、上海人工智能实验室、上海期智研究院
- **发表**：ICML 2025（arXiv 2501.18867）
- **原文 PDF**：<https://arxiv.org/pdf/2501.18867>

## 一句话结论

UP-VLA 把视觉语言模型（VLM）的「理解」能力与「未来预测」能力统一到同一个模型里：在标准 VLA 的语言/视觉问答目标之上，增加「预测未来图像」这一自监督目标作为辅助任务，让模型既会「看懂现在、听懂指令」，又会「想象接下来会发生什么」。这种统一在 CALVIN ABC→D 上带来 +33% 的任务完成长度提升。

---

## 1. 研究背景与问题定义

### 1.1 问题定位

2025 年的具身智能研究里，存在两类能力被分开优化的模型：

- **VLA（Vision-Language-Action）**：以 RT-2、OpenVLA、π0 为代表，聚焦「理解指令 + 生成动作」，核心是语言/视觉理解与动作的映射；
- **世界模型 / 视频预测模型**：以 UniPi、VPP、PAD 为代表，聚焦「预测未来」，核心是理解物理世界的动态。

这两类能力其实高度互补：一个「理解能力强但不理解物理后果」的 VLA 会在长程任务中犯短视错误；一个「预测能力强但听不懂复杂指令」的世界模型又无法执行语义丰富的任务。UP-VLA 的出发点就是把两者合并——让 VLA 在理解的同时也具备预测未来的能力。

### 1.2 与 VPP / BagelVLA 的关系

本文与 VPP、PAD 同属陈建宇组受访者（郭彦江、胡钰承、张健可）的系列工作，可视为「理解 + 预测」统一路线的早期版本，后被 BagelVLA（arXiv 2602.09849）进一步扩展为「理解 + 预测 + 动作」三位一体的更强形态。石麻笔记 EP06 专访把这条「统一建模」路线单独列为世界模型的一大分支。

### 1.3 核心贡献

1. 提出「统一理解与预测」的训练目标，把未来图像预测作为 VLA 的辅助自监督任务；
2. 验证了「预测未来」能显著提升长程操控任务（CALVIN ABC→D +33%）；
3. 为后续 BagelVLA 的「理解 + 预测 + 动作」三位一体范式奠定基础。

---

## 2. 核心方法

### 2.1 双目标统一训练

UP-VLA 在标准 VLM 架构基础上增加一个「未来预测」输出分支。训练目标包含两部分：

$$\mathcal{L} = \mathcal{L}_{\text{understanding}} + \lambda \cdot \mathcal{L}_{\text{prediction}}$$

- $\mathcal{L}_{\text{understanding}}$：语言理解（VQA / 指令对齐）与动作生成的交叉熵 / 回归损失；
- $\mathcal{L}_{\text{prediction}}$：未来图像预测损失，通常以潜变量重建或扩散目标的形式出现，让模型学会从当前观测外推后续帧。

关键设计是让「理解」与「预测」共享同一个视觉-语言骨干与潜空间，使预测未来所学到的物理动态先验能够反哺语义理解与动作决策。

### 2.2 未来预测如何帮助动作

论文的核心论点是：**能预测未来的表征，天然包含了逆动力学所需的信息**。模型为了准确预测 $t+1$ 时刻的画面，必须隐式推断「物体将如何移动、机械臂将如何运动」，这些信息恰好就是生成正确动作 $a_t$ 所需要的。因此，未来预测不是一个孤立的美学任务，而是动作学习的强正则项。

## 3. 实验与结果

### 3.1 主要定量结果

- **CALVIN ABC→D**：统一「理解 + 预测」的模型相比纯 VLA 基线，任务完成长度（Avg. Len）相对提升 **+33%**；
- 论文同时报告了在语言理解基准上的保持或提升，证明增加预测目标没有损害理解能力，反而形成互补。

### 3.2 关键结论

未来预测作为辅助任务能稳定提升长程操控能力，且代价是「多一个预测头 + 一份预测损失」，训练成本可控。这为后续把预测、理解、动作三合一的工作（BagelVLA、Motus）提供了直接证据。

---

## 4. 局限与评价

1. **预测目标的「度」需要权衡**：未来预测若权重过高，可能挤占动作生成能力；论文的 $\lambda$ 需要仔细调节，泛化到新任务时未必有统一最优值；
2. **与 VPP 的路线差异**：VPP 用「一步前向内部表征」回避了完整预测，UP-VLA 则坚持显式预测；两者在数据效率与推理速度上的取舍不同，UP-VLA 的推理链路相对更重；
3. **后续被更强的统一模型超越**：BagelVLA 与 Motus 已经在此基础上做了更深度的统一，UP-VLA 的定位更接近「统一路线的里程碑式中间产物」。
