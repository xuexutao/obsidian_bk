# π0.7：可操控通用机器人基础模型

## 基本信息

- **正式标题**：π0.7: a Steerable Generalist Robotic Foundation Model with Emergent Capabilities
- **作者**：Physical Intelligence 团队（Bo Ai、Ali Amin、Raichelle Aniceto、Ashwin Balakrishna、Kevin Black、Danny Driess、Chelsea Finn、Karol Hausman、Brian Ichter、Sergey Levine、Suraj Nair、Karl Pertsch、Allen Z. Ren、Jost Tobias Springenberg、Quan Vuong 等）
- **版本**：arXiv:2604.15483v2，2026-04-24
- **项目页**：<https://pi.website/pi07>
- **规模**：约 5B 参数；4B Gemma 3 / SigLIP VLM backbone（视觉编码器约 400M）+ 860M flow-matching action expert
- **本地原文**：`assets/π0.7 - 可操控通用机器人基础模型/sources/paper.pdf`

## 一句话结论

**π0.7 的关键不是再加一种动作头，而是把“训练轨迹为什么这样做”也写进 prompt：在任务/子任务语言之外加入 subgoal images、速度、质量、错误标记和控制模式，使同一个 5B VLA 能从优质示范、失败、旧策略 autonomous rollout、跨本体机器人数据、人类第一视角视频和 Web 多模态数据中学习而不把好坏策略平均掉；由此它开箱达到专用 SFT/RL policy 的灵巧度，在未见语言、未见本体和未见任务组合上出现 60–80% 级泛化，并在 UR5e 零样本折衣上达到 85.6% progress / 80% success，接近资深人类操作者的 90.9% / 80.6%。**

## 1. 研究背景与问题定义

### 1.1 通用 VLA 的“多样性悖论”

机器人基础模型要获得组合泛化，必须吃进更多任务、环境、本体和数据来源；但数据越大越杂，策略质量、执行速度和动作模式越不一致。传统 behavior cloning 在相同观测/指令下平均这些模式，可能把快速成功、慢速成功、错误尝试和失败 rollout 混成一个次优动作分布。因此，单纯堆数据并不必然得到更强 generalist，甚至会使性能下降。

π0.7 的问题是：**能否像文本/图像生成模型用详细 prompt 区分风格和质量那样，为每条机器人轨迹提供“做什么 + 怎样做 + 做得怎样”的条件，让模型保留数据多样性，又能在测试时明确索取高质量、快速、无错误的行为？** 这被称为 steerability：同一个策略通过改变 context 切换任务、策略、速度、控制模式和目标形态，而不是为每个任务另做 fine-tuning。

![](assets/π0.7%20-%20可操控通用机器人基础模型/figures/01-teaser.png)

> **图 1：π0.7 的训练—推理全景。** 训练端汇合机器人示范、autonomous data、Web 多模态与 egocentric human data，并用语言、subgoal image、episode metadata 消解行为歧义；推理端由高层策略和世界模型生成动态 prompt，VLA 在不做任务专用微调的情况下执行灵巧、跨本体和组合任务。  
> **来源**：论文 Figure 1，第 1 页；官方 PDF：<https://arxiv.org/pdf/2604.15483>

### 1.2 核心贡献

1. 提出 **diverse context conditioning**：任务语言、细粒度 subtask、multi-view subgoal images、episode speed/quality/mistake、joint/EE control mode 共同构成可缺省的 prompt。
2. 把失败、低质量示范和旧模型 evaluation/RL rollout 纳入预训练，并用 metadata 区分模式，使 generalist 能蒸馏专用 π*0.6 RL policy 的能力。
3. 统一 π0.6-MEM history encoder、4B VLM、860M continuous action expert、高层语言 policy 与 BAGEL-14B 初始化的轻量世界模型。
4. 展示四类涌现能力：专用策略级开箱灵巧度、复杂语言跟随、零样本跨本体策略重组、未见任务的短程组合与语言 coaching。
5. 用数据质量/规模与任务多样性控制实验说明：metadata 使低质量增量数据从“伤害模型”变成“持续提高模型”；移除最具多样性的 20% 数据比随机移除 20% 更伤泛化。

## 2. 任务定义与输入输出

### 2.1 可操控条件策略

传统 VLA 学习

$$
\pi_\theta(a_{t:t+H}\mid o_t,\ell),
$$

其中 $o_t$ 是观测、$\ell$ 是任务指令。π0.7 将条件扩展为

$$
C_t=\{\ell,\hat\ell_t,g_t,m,c\},
$$

并学习

$$
\pi_\theta(a_{t:t+H}\mid o_{t-T:t},q_{t-T:t},C_t).
$$

各变量含义为：

- $\ell$：全局任务，如 “clean the kitchen”；
- $\hat\ell_t$：当前子任务，如 “pick up the knife”；
- $g_t=[G^1_t,\ldots,G^n_t]$：多视角近未来 subgoal images；
- $m$：episode metadata，包括速度、质量、当前 segment 是否含 mistake；
- $c\in\{\text{joint},\text{ee}\}$：低层控制模式；
- $o_{t-T:t}$：最多四相机、每路最多六帧的 observation memory；
- $q_{t-T:t}$：当前与历史 proprioceptive states；
- $a_{t:t+H}$：$H=50$ 的连续动作 chunk。

### 2.2 Metadata 的定义

速度用 episode 长度表示，并按 500 steps 分桶，例如 1750–2250 步都标成 “2000 steps”；质量是人工 1–5 分，5 最好；mistake 是 segment 级布尔标签，表示抓取失败、执行错误 subtask 等。训练时 metadata 是轨迹属性，推理时它变成“期望行为”：quality 固定 5、mistake 固定 false、speed 设为该任务 episode length 的第 15 百分位，要求模型执行较快的高质量模式。

### 2.3 任务输出的两个层级

高层 policy 根据当前观测、全局任务、历史 subtask/memory 与 metadata 生成 $\hat\ell_t$；世界模型根据观测、$\hat\ell_t$ 与 metadata 生成 $g_t$；低层 π0.7 VLA 再以两者为 context 生成动作。对于新任务，人也可以实时提供 $\hat\ell_t$，形成 language coaching；收集到的 coaching 文本随后可训练高层 policy，而低层动作模型无需新 teleoperation。

## 3. 核心方法

### 3.1 总体架构

π0.7 约 5B 参数。backbone 是 Gemma 3 4B 架构与约 400M SigLIP vision encoder；视觉端采用 MEM history encoder，在固定 token 数内编码多帧；独立 860M action expert 用 flow matching 生成 50 步动作。运行时可额外挂同构高层语言 policy 与 BAGEL 初始化的 world model。

![](assets/π0.7%20-%20可操控通用机器人基础模型/figures/02-architecture.png)

> **图 2：π0.7 架构与动态 prompt。** 主 VLA 同时读取 observation memory、全局任务、子任务、subgoal images、metadata 和 proprioception；高层 policy 产生子任务，world model 产生多视角视觉子目标，action expert 从噪声生成连续动作。  
> **来源**：论文 Figure 2，第 4 页；官方 PDF：<https://arxiv.org/pdf/2604.15483>

### 3.2 History vision encoder 与 proprioception

模型最多接收四路相机：front、左右 wrist、可选 rear；每路最多 6 个 history frames，stride 为 1 秒。历史视频经 MEM 式空间—时间压缩后，输出 token 数与单帧相同。观测和 subgoal images 均 resize 到 $448\times448$。

训练时，全部 history frames 以 0.3 概率整体 dropout；rear camera 也以 0.3 概率 dropout。机器人状态不再像 π0.6 那样离散成文本，而由线性层投影到 backbone 维度，每个历史状态一个 token；若对应 history frame 被 drop，state token 同步 mask。这保持视觉与本体历史对齐。

### 3.3 Block-causal 多模态注意力

observation tokens 在自身块内双向注意，subgoal-image tokens 在自身块内双向注意且可以 attend observations；后续 text tokens 使用 causal attention。该 mask 兼顾视觉编码需要的双向上下文和文本生成的自回归约束，并确保视觉目标基于当前状态而非孤立生成。

### 3.4 Flow-matching action expert

action expert 是 860M transformer，50 个 action tokens 彼此双向注意，也可 attend VLM activations。训练从真实动作 $a_1$ 与高斯噪声 $a_0$ 构造

$$
a_\tau=(1-\tau)a_0+\tau a_1,
$$

并预测速度场：

$$
\mathcal L_{\mathrm{FM}}=
\mathbb E_{a_0,a_1,\tau}
\left\|v_\theta(a_\tau,\tau,o_{t-T:t},C_t)-(a_1-a_0)\right\|_2^2.
$$

flow timestep 通过 adaptive RMSNorm 注入。推理固定用 5 个 denoising steps 生成 50-step chunk，每次实际执行 $\hat H\in\{15,25\}$ 步后异步重规划。

### 3.5 RTC：把推理延迟纳入训练

π0.7 使用 training-time Real-Time Chunking。训练随机模拟 0–12 个 control steps 的延迟；在 50 Hz 机器人上对应最多 240 ms。策略因而学会在旧 chunk 已经执行一部分时，对剩余轨迹做条件化续接，避免动作边界跳变。UR5e 以 20 Hz 运行，其他平台以 50 Hz 运行。

### 3.6 Subtask language：从“任务名”到逐步 coaching

$\hat\ell_t$ 是随时间变化的原子指令，比全局 $\ell$ 更细。它既可来自自动高层 policy，也可由人实时说出。语言接口让一个未见长程任务被拆成已会技能的组合：如 air fryer 任务依次“抓把手—开门—拿甜薯—放入—关门”。这不是让 LLM 直接输出关节角，而是让语言选择低层 VLA 已学到的动作模式。

### 3.7 Subgoal images 与 world model

语言“open the fridge”不指定抓把手角度、双臂配置和期望物体位置。π0.7 因此引入多视角目标图 $g_t$。world model $g_\psi$ 以 BAGEL 14B mixture-of-transformers 图像生成/编辑模型初始化，在高质量 subtask segment 上训练：

$$
\max_\psi\ \mathbb E_{\mathcal D_g}
\left[
\mathcal L_{\mathrm{CFM}}\big(g_t^\star,g_\psi(o_t,\hat\ell_t,m)\big)
\right],
$$

其中 $g_t^\star=o_{t_{\mathrm{end}}}$ 是 segment 末帧。数据还混入 Web、egocentric human video 和其他视频，使生成器把非机器人语义/物理知识转为视觉目标，再由 VLA 执行动作。

训练主 VLA 时，subgoal examples 只占每个 batch 的 25%，因为目标图使动作预测近似 inverse dynamics、会显著加快该部分学习，比例过高可能让模型过度依赖。真实目标图中，25% 取 segment 末帧，75% 从未来 0–4 秒均匀采样；还大量使用 world-model generated goals，缩小训练看真图、部署看生成图的差距。

### 3.8 Prompt dropout 与可组合使用

为了让各条件可选而非硬依赖，训练做 modality dropout：

- subgoal image 仅加入 25% examples；
- 在已有 subgoal 的 examples 中，subtask text 以 30% 概率 dropout；
- 整个 metadata 以 15% 概率 dropout；
- 未整体 dropout 时，speed、quality、mistake 各自再以 5% 概率独立 dropout；
- control mode 不 dropout。

这让部署可只用语言、语言+目标图、metadata-only guidance，或全部条件。

### 3.9 Classifier-free guidance（CFG）

由于训练见过条件缺省，动作去噪可做 CFG。论文写成 action score 的组合：

$$
\nabla_a\log\pi_\theta(a\mid o,C)
+\beta\left[
\nabla_a\log\pi_\theta(a\mid o,C)-
\nabla_a\log\pi_\theta(a\mid o,C_{\mathrm{uncond}})
\right].
$$

π0.7 主要对 metadata 做 CFG，以强化快、高质量、无错误模式，$\beta\in\{1.3,1.7,2.2\}$。这相当于把生成模型里的“prompt adherence”移到动作分布上。

### 3.10 异步运行流程

初始观测到来后，高层 policy/人给出 $\hat\ell$，world model 生成 $g^\star$，组成 $C$ 后动作专家采样 50 步。之后，只要 subtask 改变或距离上次目标图超过 $\Delta=4$ 秒，就异步刷新 subgoal；动作线程每执行 15/25 步异步生成新 chunk，并通过 RTC 与已执行前缀衔接。高层、世界模型和 VLA 分线程运行，动作控制始终使用最新可用 context，不等待慢组件阻塞。

## 4. 数据与训练

### 4.1 多源训练混合

训练数据包括：

1. 多平台、多环境、多任务的高质量 robot demonstrations；
2. 旧策略的大量 autonomous evaluation episodes，包括成功、失败和有明显错误的 episode；
3. π*0.6 RL 训练/评测 rollout，用于把 specialist 行为蒸馏回 generalist；
4. rollout 中的人类 intervention/correction；
5. 开源 robot datasets；
6. egocentric human videos；
7. Web object localization、attribute prediction、VQA、text-only prediction；
8. 自有机器人视频与 Web 视频的 video captioning。

论文没有披露总 episode 数、小时数、各源 sampling 权重、优化器、batch、训练 steps 与硬件规模，因此无法进行严格同规模复现。作者明确排除了任何面向泛化测试任务所收集的 autonomous evaluation data，避免最直接的测试泄漏。

### 4.2 为什么低质量数据现在可用

普通 BC 学的是混合边际 $p(a\mid o,\ell)$；若数据中既有优质策略 $z=\text{good}$ 又有失败策略 $z=\text{bad}$，边际会平均：

$$
p(a\mid o,\ell)=\sum_z p(a\mid o,\ell,z)p(z\mid o,\ell).
$$

π0.7 把质量、速度、mistake 等模式变量 $z$ 放入 context，学习 $p(a\mid o,\ell,z)$。部署指定 $z=\{\text{quality}=5,\text{mistake}=false,\text{fast}\}$，从而利用失败覆盖的新状态，却不要求复现失败动作。这是整篇论文最核心的统计解释。

### 4.3 机器人平台与控制

平台包括双臂移动机械臂、轻量静态双臂 BiPi、双 UR5e + Robotiq、以及单臂 6-DoF 系统。全部使用 parallel-jaw gripper。动作由简单 PD controller 执行；EE 模式通过数值 inverse kinematics 转换成 joint targets。UR5e 臂更长、更重、桌边安装方式与训练主平台不同，是跨本体测试中最大的 morphology gap。

### 4.4 Baseline 与主要对照

- **π0.5、π0.6**：前代 generalist VLA；
- **π*0.6 RL Specialist**：按单任务 RL post-training 的专用高性能策略；
- **π0.6 SFT Specialist / π0.6-MEM SFT Specialist**：目标任务监督微调；
- **π0.7 (no metadata)**：去掉 episode metadata；
- **π0.7 (no eval data)**：不使用 autonomous evaluation episodes；
- **π0.7 (GC)**：运行时加入 world-model generated subgoal images；
- **w/o most diverse 20%** 与 **w/o random 20%**：等量数据下隔离任务多样性的贡献；
- **human zero-shot teleoperation**：10 名资深操作者首次在 UR5e 上折衣的参照。

## 5. 实验结果

### 5.1 开箱灵巧度：一个 generalist 对多个 specialist

Figure 6 比较同一个 π0.7 与 π*0.6 的单任务 RL specialists。在 T-shirts/shorts laundry、最难衣物折叠、espresso、box building 上，π0.7 的 success 与 normalized throughput 整体匹配 specialists，并在 diverse laundry 与 box building 的 throughput 上更高。另在 PB sandwich、inside-out shirt、drive through door、slice zucchini、peel fruits/vegetables、take out trash 上，π0.7 匹配任务专用 π0.6 SFT specialist 的 task progress。

论文图未印出全部柱值，不能把视觉读数包装成精确表格；可靠结论是**同一未针对这些评测再微调的 π0.7，在多项任务上达到分别为每项单独训练的 specialist 水平**。

### 5.2 Metadata 与 autonomous data 消融

Figure 7 的 `no metadata` 与 `no eval data` 在四个 π*0.6 任务上均落后完整 π0.7，差距在 throughput 上最明显：

- 无 evaluation data，模型不能蒸馏 RL specialist rollout；
- 有混合质量 rollout 但无 metadata，模型无法区分优劣模式，低质量轨迹会拖累动作分布；
- 二者同时存在时，失败拓宽状态覆盖，quality/mistake/speed 又允许测试时选择最佳模式。

这组消融直接支持“不是 autonomous data 本身，而是**可条件化的 autonomous data**”产生 specialist distillation。

### 5.3 Memory 与语言跟随

在 Swap 3 Mugs、Find Object、Scoop Coffee、Window Cleaning 等 MEM 任务上，单一 π0.7 开箱达到或超过针对每项微调的 π0.6-MEM specialists。语言方面，论文在 4 个未见厨房、2 个未见卧室上的 14 个 scenarios 测 3–6 步开放式指令，π0.7 显著超过 π0.5/π0.6。

复杂指代表达包括“拿起我会用来喝汤的物体”“拿最大盘子上的水果”。π0.7 比前代更强，加入 generated subgoals 后进一步提升。Reverse Bussing 和 Reverse Fridge-to-Microwave 刻意要求违反训练数据偏置；π0.7 能按语言反向执行，后者依赖视觉目标尤其明显。这说明它不只是按场景检索最常见动作。

### 5.4 零样本跨本体

![](assets/π0.7%20-%20可操控通用机器人基础模型/figures/03-cross-embodiment.png)

> **图 3：跨本体迁移结果。** 简单重排任务上三代模型都有一定迁移；当源为轻量静态双臂、目标为更大更重的 UR5e，π0.7 在 Shirt Bagging、Towel Folding、Shirt Folding 上优势扩大，generated subgoal conditioning（GC）继续提升折叠。右侧蓝虚线是资深人类首次操作 UR5e 的 task-progress 参照。  
> **来源**：论文 Figure 12，第 12 页；官方 PDF：<https://arxiv.org/pdf/2604.15483>

最强结果来自 UR5e shirt folding：训练数据没有 UR5e laundry folding。10 名资深 teleoperators 平均有 **375 小时**跨机器人经验、均位于经验 top 2%，第一次在 UR5e 做该任务时达到 **90.9% task progress / 80.6% success**；π0.7 达到 **85.6% progress / 80% success**。这比仅说“超过 baseline”更重要：模型的首次跨本体适应接近熟练人类首次换设备。

迁移不是复制源轨迹。源平台装袋常用一只手撑袋、另一只手放入；UR5e 的臂展更大，π0.7 自发采用单臂 pick-and-place。源平台折衣常用倾斜末端压住布料，UR5e 上策略改成更适合其安装位置和运动学的垂直抓取。generated subgoals 提供“目标本体下合理的未来画面”，帮助在源/目标 morphology 间建立视觉类比。

### 5.5 新任务组合：直接提示与 language coaching

短程未见任务包括 French press plunger、向 rice cooker 舀米、擦办公用品、旋转风扇/齿轮等；没有为这些任务收集机器人动作数据，π0.7 仅凭语言或 generated goals 即可执行。

长程任务（air fryer 装载/卸载、toast bagel）最长约 5 分钟，直接一句总指令仍不够。人逐步给 subtask 后，π0.7 显著优于 π0.5/π0.6，并由 subgoal images 进一步增强。随后只用 coaching episode 里的语言序列训练高层 policy，得到 fully autonomous policy；在五项任务上，autonomous progress 大致匹配 live coaching，**不需要额外低层 teleoperation/action labels**。

这表明 π0.7 的“新任务学习”分两层：低层 skill 已存在于大混合中，高层只需学习新组合顺序。它不是从零发明完全新的接触动力学。

### 5.6 数据规模 × Metadata 控制实验

作者把 Laundry (T-Shirts and Shorts) 人类示范按质量与速度切成 top 30%、50%、80%、100% 四个桶，并从头训练有/无 metadata 的 8 个模型。随着纳入更多低质量数据：

- **without metadata**：性能会下降；
- **with metadata**：性能持续提高，即使平均数据质量下降。

这直接验证条件变量把“坏数据”从要模仿的平均行为转成可利用的状态覆盖。测试时指定高质量 metadata，即可从扩大覆盖中获益而避开坏模式。

### 5.7 任务多样性消融

在相同删除比例下：完整 π0.7 和随机删除 20% 数据的模型，都显著优于删除“任务多样性最高 20%”的模型。因为数据量受控，差异不能只归因于样本数，说明长尾任务覆盖本身促进未见短程任务的组合泛化。

### 5.8 失败与边界

- 已见任务常超过 **90% success**，未见任务或未见 task–robot 组合通常只有 **60–80%**；“通用”尚不等于可靠部署。
- 长程未见任务不能只给一句总指令，仍需人类逐步 coaching 或训练高层 policy。
- generated subgoals 可能语义正确但几何不精确；主 VLA 必须容忍真实/生成目标差异。
- metadata 标签粗糙且依赖人工；错误 quality/mistake 标注可能把失败模式误当目标行为。
- 数据库极大后，严格证明某任务“从未见过”很困难；模型可能在别名、子步骤或人类/Web 数据中见过相关行为。

## 6. π 系列演进关系

### 6.1 π0：连续动作基座

π0 用 PaliGemma + flow matching action expert 证明 VLM 语义与 50-step continuous action chunk 可以统一，解决离散动作 token 的高频控制瓶颈。π0.7 保留这一动作生成内核，但 action expert 扩展为 860M，并引入更强 backbone、memory、RTC 和多条件 prompt。

### 6.2 π0-FAST / Knowledge Insulation

FAST 提供高效离散动作 token，让动作可进入语言建模训练；Knowledge Insulation/π0.6 路线隔离 VLM 与连续 expert 的梯度，减轻动作训练破坏视觉语言知识。π0.7 继续使用连续 flow expert，同时把“怎样执行”更多地放入 context，而不是只靠权重平均。

### 6.3 π0.5：开放世界与高层 subtask

π0.5 引入高层 subtask、异构知识和开放世界任务泛化。π0.7 继承 $\ell+\hat\ell_t$ 的层次接口，但把短文本扩成 language + image + metadata + control mode 的 multimodal prompt，使高层指令不仅说明“下一步是什么”，还可说明“应达到什么视觉状态、用哪种质量/速度执行”。

### 6.4 π*0.6：从部署经验学习

π*0.6 用 RL/纠正把单任务做强。π0.7 不替代 specialist learning，而是**吸收其 rollout**：把 RL specialist 的自主数据连同质量 metadata 放回 generalist 预训练，形成 policy distillation。实验显示 generalist 能匹配甚至在 throughput 上超过部分 specialist。

### 6.5 MEM：时间上下文成为默认能力

π0.7 直接采用 MEM history vision encoder、连续 state token 与记忆评测能力。MEM 解决“过去发生了什么”，π0.7 再解决“从多种历史与策略中要哪一种行为”。这也是为什么 π0.7 能开箱匹配 π0.6-MEM task-specific models。

### 6.6 Human-to-Robot：跨本体数据成为训练常态

Human-to-Robot 论文证明，当 VLA 预训练足够多样时，人类视频能像另一种 embodiment 一样被吸收。π0.7 把 egocentric human data 正式纳入训练混合，并通过 subgoals 把人类/Web 概念转成目标图，再由动作模型 grounding；其 UR5e 折衣结果是“embodiment-agnostic 表示 + 视觉目标 steering”的更强体现。

## 7. 局限与批判性评价

### 7.1 作者明确承认的局限

1. zero-shot 泛化低于 in-distribution：未见任务/组合多为 60–80%，而已见任务常 >90%。
2. 超大混合下 seen/unseen 边界难以审计；“新任务”可能是已见技能的 remix。
3. 更复杂长程任务仍需 coaching；真正自主发现任务分解尚未实现。
4. 作者建议未来利用 steerability 在测试任务上做少量 coaching 或 autonomous RL，而不是期待一次预训练解决所有问题。

### 7.2 额外批判

- **数据规模不透明**：没有总量、采样权重、训练算力和完整超参数，论文主张高度依赖无法外部审计的私有数据引擎。
- **系统不是单模型成本**：主 VLA 约 5B，高层 policy 也是大 VLM，world model 又基于 14B BAGEL；“轻量 world model”是相对大型生成模型而言，完整部署资源仍高。
- **人工 metadata 成为新瓶颈**：质量 1–5 和 segment mistake 需要标注标准；跨任务分数是否可比较、标注一致性如何，论文未详细量化。
- **CFG 可能放大错误条件**：若模型误学“短=快=好”，强 metadata guidance 可能鼓励跳步骤；速度和质量并非总是正相关。
- **subgoal 并非物理计划**：目标图描述结果，不保证中间路径无碰撞、动力学可行或安全；action expert 仍承担全部可执行性。
- **评测广但单项统计有限**：许多图只给柱状结果而无数值表、样本数和完整置信区间，难以复核小差异。

### 7.3 个人判断

π0.7 最重要的抽象是：**把数据异质性从训练噪声改写为可提示变量。** 传统数据清洗试图删除差异，π0.7 则标注差异并在推理时选择模式。这一思路可能比单纯扩大参数更关键，因为现实机器人日志天然包含失败、恢复、快慢、不同操作者和控制器。

不过，它仍依赖人工定义 metadata schema。真正可扩展的下一步应自动发现 latent strategy/quality variables，再允许用户用自然语言或少量偏好把 latent mode 对齐到“更安全/更快/更稳”。同时需要安全约束避免模型把“高速度”与危险捷径绑定。

## 8. 复现成本与实践建议

### 8.1 复现成本

| 项目 | 评估 | 依据 |
|---|---|---|
| 主模型 | 极高 | 约 5B VLA：4B backbone + 860M action expert |
| 辅助模型 | 极高 | 高层 VLM policy + BAGEL-14B 初始化 world model |
| 数据 | 极高 | 多机器人、多环境、示范、失败、RL/eval rollout、人类视频与 Web 数据 |
| 标注 | 极高 | subtask、quality 1–5、mistake segment、控制模式与 subgoal segment |
| 真机 | 极高 | 20/50 Hz 多平台，四相机，PD/IK，跨本体评测 |
| 训练细节 | 不完整 | 总数据、混合比例、优化器、steps、batch、算力未披露 |
| 代码/权重 | 低可得性 | 论文未提供 π0.7 独立公开代码或权重 |

### 8.2 可操作的缩小复现

可在开源 VLA 上先验证核心命题，不必复刻 5B 系统：选一个任务同时收集成功、慢速成功、抓取失败和恢复轨迹；为每段标注 `quality/speed/mistake`；训练 conditional policy 与无 metadata baseline；固定数据量后逐步加入低质量轨迹，观察两条曲线是否分别上升/下降。再对 metadata 做 dropout，使测试可用 CFG 选择高质量模式。

subgoal 部分可用真实未来帧先做上界：25% batch 加目标图，按论文 25% segment-end + 75% 未来 0–4 秒采样；验证动作学习是否加快。随后替换为生成目标，单独测 real→generated domain gap。跨本体实验必须保证目标机器人没有该任务数据，并报告 source/target morphology、控制频率和 human zero-shot 基线。

## 9. 个人启发与后续问题

1. **不要轻易丢弃失败 rollout。** 若能标注并条件化，失败提供成功示范没有覆盖的状态和恢复机会。
2. **策略蒸馏可以持续闭环。** specialist RL → metadata-labeled rollout → generalist pretraining → 新 specialist，是比每代丢弃旧经验更可扩展的循环。
3. **语言 coaching 是低成本高层数据。** 人不再遥操作每个关节，只需说下一步；这可能把机器人教学从动作采集转成程序/语言监督。
4. **世界模型最实用的角色可能不是长视频 rollout，而是 context generator。** π0.7 只需 subgoal image 帮动作模型 disambiguate，无需让像素预测器独自承担控制。
5. **应增加安全与校准评测。** quality/speed CFG 在高风险任务上是否会提高碰撞率？subgoal 错误时策略会拒绝、忽略还是盲从？
6. **“未见”需要数据审计工具。** 应基于视觉、语言和动作 embedding 搜索训练近邻，量化测试任务与训练库的组合距离，而不是只依赖人工声明。
