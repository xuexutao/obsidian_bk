# 世界模型与视频生成的记忆机制：架构演进综述

> **结论先看：** 这篇综述把「世界模型 / 视频生成怎么记住过去」这条横切主线，从 2022 年的 Phenaki 一路梳理到 2026 年的 Infinite-World、TTT-Video-DiT 与 Genie 3。核心结论是：**记忆机制的演进不是「模型变大」的单调故事，而是「记忆放在哪里、以什么形式存、怎么被取回」三条设计轴上的反复博弈**。
>
> - **范式全景**：记忆机制可以切成六大类——历史帧·滑动窗口、显式 3D 几何、外部记忆库+检索、记忆压缩、循环隐状态（SSM/LSTM/TTT）、训练对齐（Forcing）；但更本质地，它们收敛成**隐式 / 显式 / 混合**三条架构路线。
> - **演进主线**：从「靠 context window 硬记」起步，2024 年底实时交互（Oasis、Genie 2）暴露了重访漂移与 KV 成本爆炸，逼出 2025 年「显式几何 + 检索 + 压缩」的百花齐放，再到 2025 末–2026 年「循环隐状态 + 训练对齐」走向分钟级甚至小时级一致性。
> - **我的判断**：下一个真正拉开差距的方向大概率是**「循环隐状态（SSM/TTT）+ 训练对齐」这条线**——显式几何与检索在动态、通用、大规模场景下都有扩展天花板，而可扩展的分钟级一致性最终要靠「把无限历史压进一个能持续演化的隐状态」。
>
> **总体评级：★★★★☆（4/5）**——作为「记忆机制方向的地图册 + 架构演化史」，本综述把三条路线和五个演进阶段讲透了。扣分点：（1）涉及论文多达 30+ 篇，其中多数（RELIC、Infinite-World、VMem、Spmem、TTT-Video-DiT 等）尚未单独精读原文，本综述以 arXiv 摘要、官方博客与二手综述交叉验证为依据；（2）配图为综述自绘示意图，非论文原图；（3）部分 2026 年新工作的 arXiv 编号尚未逐一核对。

## 1. 研究背景：为什么世界模型需要记忆

### 1.1 记忆问题的本质：一个 POMDP 问题

「世界模型」（world model）这个概念可以追溯到 Kenneth Craik 上世纪中叶的思想——一个在脑中镜像外部世界、能做反事实预测的表示。在今天的机器学习语境下，世界模型通常被形式化为一个**部分可观测马尔可夫决策过程（POMDP）** 的元组 $(S, A, O, T, R)$：$S$ 是世界状态，$A$ 是动作，$O$ 是观测，$T$ 是转移函数 $p(s_{t+1} \mid s_t, a_t)$，$R$ 是奖励。

而**交互式视频世界模型（Interactive Video World Model, IWM）** 把「世界模型」落成了一件非常具体的事：给定交互历史 $H_t$、当前动作 $a_t$ 和条件 $c_t$，递归地预测下一帧观测：

$$o_{t+1} \sim p_{\phi}(o_{t+1} \mid H_t, a_t, c_t),\qquad H_t = \{o_{1:t}, a_{1:t-1}, c_{1:t-1}\}$$

这个式子看起来简单，却把「记忆」这件事钉死在了三个地方。

**第一，部分可观测性（object permanence）。** 相机一转，墙后面的东西就出了视野。但真实世界里的东西不会因为「看不见」就消失——一个行人走进一辆停在路边的卡车后面，他仍然存在、仍然在移动。模型必须「记住」看不见的东西，等相机转回来时把它以一致的身份和状态「还原」出来。这正是 Genie 2 宣传里那句「记住并精确还原暂时离开视野的场景」对应的能力。

**第二，重访一致性（revisit consistency）。** 玩家绕一圈回到原点，场景应该和刚才几乎一样——墙还是那面墙，门还是那扇门。传统生成式视频最大的软肋就是：一旦某帧被「忘记」，重新生成时会悄悄换掉墙的颜色、改变房间布局。这不是画质问题，是「世界是否连续存在」的本体论问题。

**第三，状态持久性（state persistence）。** 动作带来的改变必须留下来：打开的门不能自己合上，踩过的脚印不能凭空消失。这要求记忆不仅能存「当前看见什么」，还要存「过去发生了什么」。

### 1.2 三条互相撕扯的约束

记忆机制的设计，本质上是在三条互相矛盾的约束之间做权衡：

**约束一：长程一致 vs 注意力二次复杂度。** Transformer 的因果注意力要「记住」第 $t$ 帧，就得把它留在 context 里参与每一帧的自注意力。但自注意力的计算和显存都随序列长度 $L$ 呈 $O(L^2)$ 增长。视频的 token 数又天然巨大——一段 16 帧、256×256 的视频就有上百万像素，展平成 token 后序列长度轻松破万。这意味着「靠堆 context 硬记」很快就会撞上算力墙。

**约束二：一致性 vs 动作响应性。** 直觉上，喂给模型的历史越多，生成越连贯；但历史过多会「稀释」当前动作的影响——模型变得过度依赖「历史说了什么」而忽视「你现在要它做什么」。Astra 这类工作甚至要主动往条件帧里加噪声，逼模型多听当前动作的话。这是一对少有人意识到的矛盾。

**约束三：自回归误差累积（exposure bias）。** 世界模型是自回归的：第 $t$ 帧的预测误差会喂进第 $t+1$ 帧的条件，误差像滚雪球一样累积。训练时模型看到的是「干净的真值帧」，推理时看到的却是「自己预测的、带噪声的帧」——这个 train-inference mismatch 是长程漂移的根源。记忆机制再好，如果训练和推理的分布对不齐，也会被误差累积拖垮。

这三条约束共同解释了为什么「记忆」会成为世界模型的一个独立研究子领域，而不是「把模型做大就自动解决」的附带问题。

## 2. 记忆机制的范式分类全景

### 2.1 两大元范式：记住「在哪里」还是记住「是什么」

在切开具体机制之前，必须先做一个顶层区分。`Awesome-World-Models-with-Memory` 这个整理库把它讲得很清楚：记忆增强世界模型存在两个**元范式**，两者的记忆角色和失败模式有本质区别。

**范式 I：动作条件交互式世界模型。** 输入是动作（键盘、相机轨迹、摇杆）+ 初始状态，记忆的角色是记住「**在哪里**」——空间布局、几何结构。动作提供了强结构约束，所以记忆只需要回忆「那个地方有什么」。核心失败模式是**重访不一致、控制下的空间漂移**。评估焦点是空间一致性、重访保真度、动作跟随。

**范式 II：纯视频生成 / 叙事。** 输入是文本提示、参考图像、分镜脚本，没有动作信号，记忆必须独立编码「**是什么**」——实体身份、状态、叙事。核心失败模式是**实体漂移、状态遗忘、跨镜头叙事不连贯**。评估焦点是实体持久性、状态连续性、跨镜头一致性。

这个区分的价值在于：**把两者混在单一排行榜里会混淆根本不同的能力**。交互式世界模型的记忆是「几何记忆」，纯视频生成的记忆是「实体记忆」，它们共享机制词汇（压缩、检索、KV cache），但优化的目标函数不同。

### 2.2 六大机制范式

![](assets/世界模型记忆机制架构演进%20-%20Survey/figures/01-paradigm-taxonomy.svg)

> 图 1：世界模型记忆机制的范式全景。顶层是两大元范式，底层是六类共享的机制范式。  
> 来源：综述自绘示意图，基于 Awesome-World-Models-with-Memory 的分类体系整理。

六类机制范式分别是：

1. **历史帧·滑动窗口（History Frames as Condition）**：把最近若干帧+动作直接拼进输入，靠因果注意力 / KV cache 记状态。最朴素，是几乎所有工作的起点。
2. **显式 3D 几何记忆（Explicit 3D Geometric Memory）**：把场景重建为点云 / surfel / 3DGS 当持久记忆。有几何锚点，重访天然一致。
3. **外部记忆库 + 检索（External Memory + Retrieval）**：存历史帧 / 特征 / 实体槽，生成前按 FOV 重叠或特征亲和度检索相关记忆再注入。
4. **记忆压缩（Memory Compression）**：把无限历史压进固定预算的表示（分层压缩、轨迹打包、context token 压缩）。
5. **循环隐状态（Recurrent / Hidden State）**：用 SSM / LSTM / TTT 做持久内部状态，规避二次注意力。
6. **训练对齐 / Forcing（Training Stability）**：严格说是「记忆能不能被用好」的训练侧保障，用 Diffusion Forcing、Context Forcing、Self-Forcing、循环一致性去压自回归的曝光偏差。

后文会看到，这六类在实际工作中几乎从不孤立出现，而是以「隐式 / 显式 / 混合」三条路线的方式组合。

## 3. 三条架构路线：隐式 vs 显式 vs 混合

如果只看「记忆放在哪里」，六类机制可以收敛成三条最本质的架构路线。

![](assets/世界模型记忆机制架构演进%20-%20Survey/figures/03-memory-routes-comparison.svg)

> 图 2：隐式 / 显式 / 混合三条记忆路线的对比。隐式靠模型内部状态硬记，显式靠外部结构化存储+检索，混合把近期隐式与长期显式结合起来。  
> 来源：综述自绘示意图。

### 3.1 隐式记忆：context window 与 KV cache

隐式记忆不建任何外部存储，让历史信息「溶解」在模型内部状态里。最原始的形态就是**把历史帧直接留在 context 里**，让因果 Transformer 的自注意力去处理「哪些历史与当前帧相关」。这里的「记忆」物理上就是 Transformer 的 **KV cache**——每处理一帧，就把它的 key / value 向量追加进缓存，后续帧的 query 会去 attend 这些历史向量。

Genie 2 是这条路线最纯粹的标本。它没有任何显式 3D 表示，没有 mesh、纹理或几何存储，只有模型权重 + 一个装着近期 latent 和动作的自回归 context window。相邻帧之间的一致性完全来自 Transformer 对近期 latent 的注意力，而不是任何「存储的场景状态」。这带来的两个后果：其一，它随模型容量而非世界复杂度扩展（能渲染森林的模型也能渲染山脉）；其二，它**没有硬保证**——重访时世界不保证一模一样。DeepMind 宣传的「一分钟记忆」，独立评测（Ars Technica）实测有效窗口只有 10–20 秒。

隐式记忆的优点是「零重建误差」——因为没有显式存储，也就不存在「存错了」的问题，且实现最简单。缺点是成本随长度增长：注意力是 $O(L^2)$，KV cache 显存随长度线性增长且不可压缩（除非引入专门的压缩手段，那就滑向了混合路线）。

### 3.2 隐式记忆的进阶：循环隐状态（SSM / LSTM / TTT）

为了把「隐式」从 $O(L^2)$ 的注意力里解放出来，一条路线是回到**循环状态**：让一个固定大小的隐状态随时间演化，$h_t = f(h_{t-1}, x_t)$，用「隐状态」替代「整个 context」承担记忆。

**状态空间模型（SSM）** 是当前最热的一支。SSM 把序列建模写成一个线性时不变系统：

$$h_t = \bar{A} h_{t-1} + \bar{B} x_t, \qquad y_t = \bar{C} h_t$$

其中 $h_t$ 是隐状态，$\bar{A}, \bar{B}, \bar{C}$ 是离散化后的系统矩阵（Mamba 系进一步让它们随输入变化）。因为状态转移是线性的，可以并行扫描、用 $O(L)$ 而非 $O(L^2)$ 处理整段序列。**Long-Context SSM Video World Models**（ICCV 2025）正是把这套东西用在了视频世界模型上：它没有用一次 SSM 扫描处理整个视频，而是设计了**分块 SSM 扫描（block-wise SSM scanning）**——把长序列切成可管理的块，用 SSM 的隐状态跨块传递信息，从而在牺牲部分块内空间一致性的代价下换取大幅扩展的时间记忆；再用**局部稠密注意力**弥补分块带来的空间连贯性损失。在 Memory Maze 和 Minecraft 上，它超越了 baseline 的长程记忆保持，同时维持了可交互的推理速度。

**TTT（Test-Time Training）** 走得更极端。TTT-Video-DiT（CVPR 2025）的思路是：与其用一个固定形式的隐状态，不如让**隐状态本身是一个（小）神经网络**。TTT 层在测试时用输入 token 快速更新这个内层网络的权重，从而获得比 SSM / Mamba 更强表达力的压缩。它的效果很直接——能生成一分钟、300k+ token 的视频，领先基线 34 Elo 分。这里的哲学是「记忆不该是被动存储，而该是主动压缩」，隐状态从「向量」升级成了「程序」。

**LSTM 也没有退场。** RAD（2025）在扩散 Transformer 里塞入 LSTM 作为全局记忆、搭配局部注意力；VideoSSM 则用「滑动窗口局部无损缓存（短记忆）+ SSM 压缩全局状态（长记忆）」的混合结构，把生成当作一个循环动力系统。

### 3.3 显式记忆：3D 几何与检索库

显式记忆把「记忆」变成**模型之外、可以索引和检索的结构化存储**，又分两支。

**第一支：显式 3D 几何。** 直接把场景重建为点云、surfel（表面元素）或 3DGS，几何结构本身就是持久记忆。VMem 用 surfel 索引历史视图，把过去看到的画面锚定到表面元素上；Spatia 用视觉 SLAM 持续更新一个显式的 3D 场景点云；Spmem 把记忆拆成「增量更新的静态点图」和「稀疏情景帧」两层——静态背景用点图记（几何一致），前景动态用稀疏帧记（保动态）。这条路的优点是**有几何锚点，重访天然一致**，因为「转回来看同一块空间」这件事在几何上是明确的。缺点是**动态物体（out-of-sight 的主体）处理差**，且 3D 重建本身会引入误差、有分辨率上限。

**第二支：外部记忆库 + 检索。** 不重建 3D，而是把历史帧 / 特征 / 实体槽存进一个记忆库，生成新内容前检索最相关的记忆注入。Context-as-Memory（SIGGRAPH Asia 2025）直接存历史帧，按**相机 FOV 重叠**过滤相关帧；HyDRA 则更进一步，用**特征级亲和度**检索——因为「按几何重叠检索」在主体移动到新位置时会失效，只有按特征相似度才能把「走到镜头后、换了位置的人」以一致身份找回来。HyDRA 的价值在于点破了一个关键问题：**纯几何检索救不了动态主体**，需要的是「特征亲和」这种更软的关联。

### 3.4 混合记忆：近期隐式 + 长期显式

到了 2025 年中，一个共识逐渐成形：**单一机制扛不住分钟级一致性，必须把「近期隐式」和「长期显式」缝起来**。

RELIC（2025）是这条路线最完整的标本。它把记忆分成两层：**近期 KV cache**（最近的历史，无损、快）和**压缩的长期空间记忆**（把高度压缩的历史 latent token——含相对动作和绝对相机位姿——塞进 KV cache）。再用**自蒸馏 / self-forcing** 把双向教师蒸馏成因果学生，从而在训练期对齐「带完整上下文的教师」和「只能看过去的因果学生」。结果是 14B 模型跑出 16 FPS，动作跟随和空间记忆检索都显著优于基线。

Spmem 的「静态点图 + 稀疏情景帧」、MosaicMem 的「显式 + 隐式」也都是混合记忆的变体。它们的共同逻辑是：**显式结构负责「长期、可索引、几何一致」，隐式状态负责「近期、无损、响应快」**——用分工去对冲单一机制的固有短板。

## 4. 演进流程与关键节点

### 4.1 从固定长度到滑动窗口

![](assets/世界模型记忆机制架构演进%20-%20Survey/figures/02-evolution-timeline.svg)

> 图 3：世界模型记忆机制的演进时间线，五个阶段。  
> 来源：综述自绘示意图。

**阶段一（2023 前）：固定长度视频扩散，没有记忆需求。** Phenaki、LVDM 这类早期工作只生成一段固定长度的视频，「记忆」不是一个问题——因为根本不需要跨出当前片段。Phenaki 用时间因果注意力 + 视频 tokenizer 生成可变长度 token，但本质仍是「一次生成一段」。

**阶段二（2023–2024 初）：滑动窗口自回归。** 为了让视频「无限长」，出现了自回归的滑动窗口预测：Genie 1、DIAMOND、UniSim 这类工作把「固定长度的过去帧」拼进条件，逐帧往外推。记忆的物理载体就是 context window + KV cache。这是「记忆」第一次成为一个显式机制，但它的天花板也立刻显形：窗口有限、$O(L^2)$ 成本、重访不一致。

### 4.2 实时交互暴露的记忆危机

**阶段三（2024.10–12）：实时交互 + 长时记忆爆发。** 两个标志性事件把记忆问题推到了台前。

**Oasis（Decart / Etched，2024.10）** 第一个把「可玩的 Minecraft 世界模型」做成了浏览器里 20 FPS 的实时产品，证明了实时交互世界生成可行。**Genie 2（DeepMind，2024.12）** 则把「单图进入可导航 3D 世界」和「长时记忆」作为卖点——它声称能记住离开视野的场景并还原。

但这两个 demo 也**暴露**了两个此前被回避的硬伤：其一，**重访漂移**——Genie 2 的「一分钟记忆」实测只有 10–20 秒，重访时场景会悄悄变形；其二，**KV 成本爆炸**——实时长 rollout 下，attention 的 $O(L^2)$ 和 KV cache 的无界增长让「分钟级」成为工程上几乎不可能的事。这两个痛点，正是接下来两年记忆机制研究的主要靶子。

### 4.3 显式几何与检索的兴起

**阶段四（2025）：显式几何 + 检索 + 压缩百花齐放。** 针对重访漂移，出现了 VMem（surfel 索引）、Spmem（静态点图+情景帧）、Spatia（SLAM 点云）、Context-as-Memory（FOV 重叠检索）、HyDRA（特征亲和检索）；针对 KV 爆炸，出现了 RELIC（KV cache 压缩）、Infinite-World（分层无姿态压缩，1000 帧视界）、WorldPack（轨迹打包）。这一年是记忆机制最密集的「方法井喷」期，但也是「各家各显神通、尚无统一范式」的战国时代。

### 4.4 循环隐状态与训练对齐

**阶段五（2025 末–2026）：循环隐状态 + 训练对齐，走向分钟级。** 人们逐渐意识到，显式几何和检索在动态、通用、大规模场景下有扩展天花板，于是注意力回到「可扩展的隐式记忆」：Long-Context SSM（块状 SSM 扫描）、TTT-Video-DiT（隐状态即网络）在机制侧突破 $O(L^2)$；Diffusion Forcing、Context Forcing、Self-Forcing、LIVE（循环一致性训练）在训练侧压曝光偏差。Genie 3（2025.08）把一致性从「几十秒」推到「数分钟」，实时 720p@24fps，成为这条路线在工业界的旗手。

## 5. 代表性方法精读

### 5.1 Genie 2：靠 context window 硬记的极限

Genie 2 是「隐式记忆」路线的极限标本，值得单独解剖——不是因为它的机制先进，恰恰是因为它**把最朴素的做法推到了工程边界**，从而为后续所有「进阶机制」划定了参照系。

它的核心是**自回归潜变量扩散模型**：视频帧先经自动编码器压成 latent，再喂给一个大规模 Transformer 动力学模型；Transformer 用**因果掩码**训练（和 LLM 同款）；推理时逐帧自回归采样，每一步用「单个动作 + 先前的 latent 帧」预测下一帧。动作控制用无分类器指导（classifier-free guidance）增强可控性。

关键在于它**没有 3D 表示**。Genie 2 的世界不在任何几何结构里，只在「模型权重 + 近期 context」里。它能不能「记住」一堵墙，取决于这堵墙的 latent 有没有落在当前 context window 的 attention 范围内。这带来一个深刻的分野：传统游戏引擎把世界「完整描述在内存里」再逐帧绘制，而 Genie 2 必须「每一步从权重+近期 context 重新重建世界」。前者有硬保证，后者没有——这就是为什么它的「长时记忆」在独立评测里缩水到 10–20 秒。

Genie 2 的意义在于：它把「无显式记忆的隐式路线」的**上限和下限同时暴露了出来**——上限是「随容量扩展、无需任何工程」的优雅，下限是「重访无保证、记忆窗口短」的脆弱。2025 年之后所有「显式几何」和「压缩记忆」的工作，本质上都是在补 Genie 2 的这两个窟窿。

### 5.2 RELIC：KV cache 里的压缩长期记忆

RELIC（2025）是「混合记忆 + 压缩」路线最完整的代表，它的设计回答了「如何在保持实时交互的同时把记忆压进 KV cache」。

核心思路分两块。**记忆结构上**，它用「高度压缩的历史 latent token」作为长期记忆，这些 token 同时编码了**相对动作**和**绝对相机位姿**，然后塞进 KV cache 参与后续帧的注意力。也就是说，长期记忆不是「存原始帧」，而是「存压缩的、带姿态标注的 latent」，既省显存又保留了空间可索引性。

**训练上**，它用**自蒸馏 / self-forcing** 解决曝光偏差：先训练一个能看到完整上下文的**双向（非因果）教师**，再把它蒸馏成一个只能看过去的**因果学生**。这个「双向教师 → 因果学生」的蒸馏，正是把「训练期能用的完整信息」翻译成「推理期只能用的因果信息」的关键，也是它 16 FPS 下动作跟随和空间记忆检索都强的来源。14B 的体量跑出实时，说明压缩记忆在工程上是可行的。

### 5.3 Long-Context SSM：块状 SSM 扫描

Long-Context SSM Video World Models（ICCV 2025）代表「循环隐状态」路线在视频世界模型上的落地。它的核心洞察是：**SSM 天生适合因果序列建模，此前把它「改造」用于非因果视觉任务是南辕北辙**。

它的关键设计是**块状 SSM 扫描**：不是用一次 SSM 扫描吃下整段视频，而是把长序列切成块，用 SSM 的隐状态**跨块传递信息**——每处理完一个块，隐状态作为「压缩摘要」传给下一块。这样做的代价是「块内的空间一致性」被部分牺牲，但换来了「时间记忆」的大幅扩展。为了补回空间连贯性，它在块内和相邻帧之间加**局部稠密注意力**。这种「全局（SSM）+ 局部（注意力）」的双重结构，同时拿到了长期记忆和局部保真度，且在 Memory Maze、Minecraft 上维持了可交互的推理速度。

它和 RELIC 形成鲜明对照：RELIC 是「在注意力框架里压 KV cache」，SSM 路线是「跳出注意力、换一个线性复杂度的记忆载体」。两者都在回答同一个问题——怎么用亚二次的代价装下长记忆。

### 5.4 TTT-Video-DiT：隐状态即神经网络

TTT-Video-DiT（CVPR 2025）把「隐式记忆」推到哲学层面：**如果隐状态必须压缩一段历史，那最表达力的隐状态不是一个固定向量，而是一个能自我更新的小网络**。它在预训练 Transformer 里插入「测试时训练」（TTT）层，测试时用输入 token 快速更新这个内层网络的权重——隐状态从「被写进」变成了「被训练」。结果是一分钟、300k+ token 的视频生成，比 SSM / Mamba 更有表达力。它和 SSM 路线的区别，本质是「记忆载体」从「线性系统状态」升级到「可学习函数」。

### 5.5 VMem / Spmem：显式几何记忆的两层分化

显式几何这条线内部也有分化。**VMem** 用 surfel（表面元素）索引历史视图——把过去的画面锚定到 3D 表面元素上，重访时按「3D 空间重叠区域」检索过去的视图。这适合**静态场景**。

**Spmem** 则把记忆拆成两层以处理**动态前景**：「增量更新的静态点图」负责长期、几何一致的背景，「稀疏情景帧」负责前景动态。这个「静 / 动解耦」是显式记忆处理动态物体的关键一步——因为纯几何点图记不住「会动的东西」。

而 **HyDRA** 更进一步指出：即便这样，当主体「走到镜头后、再换个位置回来」时，几何重叠检索仍然会失效（主体不在原位置了）。它改用**特征级亲和度**检索，在 latent 空间「追踪」主体的身份，让主体以一致的外观和运动重新入镜。这是显式记忆从「几何硬检索」走向「特征软关联」的转折点。

### 5.6 Infinite-World：分层无姿态压缩

Infinite-World（2026）代表「压缩记忆」路线的当前 SOTA。它的**分层无姿态记忆压缩器（HPMC）** 递归地把历史 latent 压缩到固定预算，不依赖姿态信息（因此更通用）；再配合**重访密集微调**激活「回环闭合」——专门让模型在「回到去过的地方」时能对得上。结果是 1000 帧视界、且开源代码和权重。它和 RELIC 同属「把无限历史压进固定预算」的路线，但用「无姿态」替代 RELIC 的「姿态标注」，用「回环闭合微调」替代「自蒸馏」，通用性更强。

## 7. 局限与批判性评价

### 7.1 各路线的固有短板

**隐式（context / KV cache）**：$O(L^2)$ 成本、KV cache 无界增长、重访无硬保证。Genie 2 的 10–20 秒有效记忆就是它的天花板。

**循环隐状态（SSM / TTT）**：隐状态是「有损压缩」，长期信息会随状态演化被逐步遗忘；SSM 的线性假设对高度非线性的视觉动态未必够用；TTT 的测试时训练带来额外推理开销和训练复杂度。而且——**它们目前更多在「纯视频生成」上验证，在「动作条件的交互式世界模型」上的长程记忆证据仍相对薄弱**。

**显式几何**：动态物体难处理（VMem 明确只面向静态场景），3D 重建有误差和分辨率上限，且重建引入的「存错」问题（重建误差被当成记忆固化下来）比隐式更隐蔽。

**检索式**：检索质量受制于「相关性度量」的选取——FOV 重叠救不了移动主体（HyDRA 的动机），特征亲和则可能引入语义漂移。且检索+注入的额外延迟对实时交互是负担。

**训练对齐 / Forcing**：各类 Forcing 都在缓解曝光偏差，但都只是「缓解」，没有根治；且 Forcing 策略（Diffusion vs Teacher vs Context vs Self）之间缺乏系统的横向对照，很多论文各说各话。

### 7.2 评测的缺失

记忆机制最大的方法论问题是**「记忆好不好」没有一个公认的度量**。传统指标（FID、FVD）衡量单帧质量和短程流畅度，对「第 200 帧的墙还是不是第 20 帧那面墙」几乎不敏感。专门的记忆基准才刚刚出现：LoopNav（Minecraft 回环重访）、MIND（2026，开放域闭环重访）是起步，但覆盖面、动态主体、小时级一致性都还远未覆盖。这导致大量工作用「自报的 demo 时长」替代「可复现的评测」，横向比较缺乏可信度。

### 7.3 未解决的开放问题

1. **分钟级 → 小时级**：从 Genie 2 的秒级到 Genie 3 的分钟级是巨大进步，但小时级一致性（一个 agent 在同一个世界里活动数小时）仍然没有可行方案。这需要「分层记忆」（短期运动 + 长期场景）+ 全局世界状态召回，目前只是综述里的展望。
2. **动态 out-of-sight 主体的长期追踪**：HyDRA 只做到了「短时」的特征亲和追踪，长时间、多主体、遮挡密集的场景仍是空白。
3. **Forcing 的统一理论**：为什么「训练时往历史帧加噪声」能同时改善一致性和动作响应，缺乏一个统一的形式化解释。
4. **记忆的「可解释 / 可编辑」**：所有记忆机制都是黑箱，没有一个能让用户「查看或修改模型记住了什么」的接口——这对世界模型真正走向 agent 训练和产品化是硬缺口。

## 8. 个人判断与趋势展望

**判断一：下一个分水岭是「循环隐状态 + 训练对齐」，而不是「更大的显式记忆」。** 显式几何（点云/surfel/3DGS）在「重访一致性」上确实立竿见影，但它的扩展天花板很低——动态物体、开放世界、通用场景都在它的能力圈外。检索式受制于相关性度量。真正能「随规模扩展」的记忆，最终还是要回到「把历史压进一个持续演化的隐状态」，也就是 SSM / TTT + Forcing 这条线。我押这条线会是 2026–2027 的主战场。

**判断二：「混合记忆」是过渡态，不是终态。** RELIC、Spmem、MosaicMem 的「近期隐式 + 长期显式」分工很优雅，但它的「显式」部分仍然背着几何/检索的包袱。随着循环隐状态（尤其是 TTT 这种高表达力载体）成熟，显式部分可能被逐步吸收进隐式状态，「混合」收敛回「更强的隐式」。

**判断三：训练对齐（Forcing）是被低估的「记忆基础设施」。** 一个再好的记忆结构，如果训练-推理分布对不齐，也会被自回归误差累积拖垮。LIVE 的循环一致性、RELIC 的自蒸馏、WorldPlay 的 Context Forcing，都是在「记忆之外」解决「记忆能不能用」的问题。这条线的工作量会被低估，但它可能比「换个记忆载体」更关键。

**判断四：评测会成为瓶颈。** 方法井喷之后，没有 LoopNav / MIND 这类「专门测重访和记忆」的基准，整个方向会陷入「各报各的 demo」。谁先把「记忆评测」标准化，谁就能主导叙事。
