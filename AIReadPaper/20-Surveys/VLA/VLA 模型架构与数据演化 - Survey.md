## 结论先看（TL;DR）

如果只记五件事，请记这五件：

1. 动作表示是 VLA 架构的灵魂：从 RT-2 / OpenVLA 的离散动作 token（把连续动作量化成 256 个 bin），到 Octo 的扩散头、π0 的 flow matching，再到 Qwen-VLA / GR00T N1 的 DiT + flow matching，连续动作流已成为默认范式——因为它能表达多模态动作分布、支持长时域动作块（action chunking），并能与高频控制解耦。
2. 骨干正在"收敛"到通用 VLM：RT-1 的专用 CNN+Transformer → RT-2 的 PaLI-X 55B → OpenVLA 的 Prismatic-7B → π0 的 PaliGemma → Qwen-VLA 的 Qwen3.5-4B。趋势是"视觉语言底座 + 轻量动作解码头"的分离式设计，而非为每个本体重训一个大模型。
3. 数据从"稀缺遥操作"走向"无限生成/人类视频"：真实遥操作数据的规模从 RT-1 的 13 万条，涨到 OXE 的 100 万+（22 本体），再到 AgiBot World 的 100 万+（217 任务）；而 2026 年的前沿已把世界模型前移为数据引擎（GigaBrain-0）和人类视频转化为预训练语料（VITRA / DreamZero）。
4. 监督粒度正在被重构：从 task-level（整条轨迹一个奖励/标签）下钻到 primitive-level（PrimitiveVLA 的可复用动作原语），这是数据效率与长程泛化突破的关键，而非简单加数据。
5. 视觉对齐从"显式"走向"隐式"：早期靠显式 grounding（检测目标框），如今用目标区域重建（ReconVLA）、训练期 3D 前缀（GaussianDream）、未来视频预测（DreamZero）来做隐式对齐，代价更低、泛化更好。

### 2026 下半年的范式修正与新判断

第 1–4 章基于 7 篇精读论文得出的上述 5 个判断，在 2026 下半年遇到了一波集中修正。下文 6、7、8 是必须更新的判断：

6. 动作表示之争还没结束：连续 flow matching 与"离散扩散"是并行 SOTA。第 2.1 节认为"连续动作流（flow matching / DiT）是默认范式终点"，但 2026 年下半年出现的 MMaDA-VLA（arXiv:2603.25406）证明：把动作重新离散化，但用"离散扩散（masked token 去噪）"而非"自回归"来生成，同样能达到甚至超过连续流的水平（LIBERO 98.0% / CALVIN 4.78），且天然支持"未来目标观测 + 动作块"联合生成，无需外挂世界模型。这是动作表示的"第二次革命"——不是连续替代离散，而是离散扩散与连续流平分秋色。
7. 世界模型从"数据引擎"升级为"统一具身底座（WAM = WM + Action）"。第 3.3 节把世界模型定位为"数据引擎"（GigaBrain-0），但 2025 年底生数科技 + 清华的 Motus（arXiv:2512.13030）已经把"视频生成 + 动作生成 + 语言理解"统一进一个 Mixture-of-Transformers（MoT）架构，用 UniDiffuser 调度器在同一模型内支持 VLA / World Model / 视频生成 / 逆动力学 / 视频-动作联合预测五种模式，在 RoboTwin 2.0 取得 87.02% 平均成功率（较 π0.5 提升约 45 个百分点），并首次在具身模型中画出可预测的 scaling law——这是"具身智能的 GPT-2 时刻"。这意味着世界模型不再只是"辅助模块"或"数据引擎"，而是要取代 VLM 成为统一的具身底座。
8. 空间与记忆建模成为新的主战场。前文低估了"视觉空间表征"对 VLA 泛化的决定性作用。CVPR 2026 冠军奖论文（arXiv:2512.02902，中大 + X-Era AI Lab）证明：VLA 在新视角任务上的失败，根因不是"不懂物理"，而是"看到的空间变形了"——只需用 FTM（4K 参数）或 FLA（4.7M 参数）轻量校准视觉空间表征，就能把 LIBERO 新视角成功率从 48.5% 拉到 87.1% / 90.8%，且参数效率比 LoRA 高约 99 倍。AtlasVLA（arXiv:2608.06729）则从另一个角度解决"单腕相机 + 长程任务"的双遗忘问题：4D 持久世界状态记忆（体素哈希）+ ego 工作状态记忆，驱动 DiT，仅用单腕相机即在 LIBERO-Long 提升 9.4%、真实长程提升 17.5%，超过多视角基线。这标志着 2026 年 VLA 的主战场已从"换骨干 / 加数据"转向"更聪明的空间与记忆"。

## 1. 研究背景：VLA 为什么是具身智能的核心问题

### 1.1 问题定义

VLA（Vision-Language-Action）模型试图回答一个统一的问题：**给定一段自然语言指令和当前的视觉观测，直接输出机器人应该执行的动作序列**。它把视觉（Vision）、语言（Language）与动作（Action）三个模态揉进同一个可训练、可泛化的参数模型里，目标是让机器人不需要为每个任务、每个场景、每个本体单独编写策略，而是像大语言模型那样"预训练 + 微调 / 零样本迁移"。

形式化地，一个 VLA 模型学习条件分布：

$$
\pi(a_{t:t+H} \mid o_{t}, \ell)
$$

其中 $o_t$ 是时刻 $t$ 的视觉观测（单帧或多帧），$\ell$ 是语言指令，$a_{t:t+H}$ 是未来 $H$ 步的动作序列。$H$ 就是"动作块长度"（action chunking），它决定了模型一次推理能规划多远的未来。

这个形式本身看似简单，但它把两个根本矛盾摆在了台面上：

- **动作是高频、连续、低维的，语言是低频、离散、高维的**。怎么在同一个模型里调和这两种截然不同的信号？
- **机器人数据极其昂贵**（真实遥操作一分钟就要几美元到几十美元），而视觉语言数据近乎无限。怎么用廉价的"类机器人"数据（人类视频、仿真、世界模型生成）去弥补昂贵的真实数据缺口？

这两条矛盾，正是本综述"架构演进"与"数据演化"两条主线的源头。

### 1.2 为什么是"两条线"而非"一篇模型罗列"

早期对 VLA 的梳理容易陷入"RT-1 做了什么、RT-2 做了什么"的方法罗列。但真正推动这个领域前进的，是两个反复出现、互相咬合的**问题**：

- **架构侧的问题**：动作该怎么表示？骨干该用谁？监督信号该打在哪一层粒度？视觉和动作该怎么对齐？
- **数据侧的问题**：数据从哪来？什么形态（遥操作 / 仿真 / 生成 / 人类视频）？规模要多大？监督信号够不够密？

本综述以这两个问题为主轴，把 7 篇精读论文分别放进"架构"与"数据"两条线中，并在最后讨论它们如何交汇。

## 2. 架构演进：动作表示、骨干、监督粒度与视觉对齐

### 2.1 动作表示：从离散 token 到连续动作流

VLA 架构最底层的决策，是**动作在模型内部如何被表示**。这个决策几乎决定了后续所有设计。

#### 2.1.1 离散动作 token 时代（RT-1 → RT-2 → OpenVLA）

最早把"动作"塞进 Transformer 的做法，是模仿语言模型的 token：**把连续动作量化成离散的桶（bin）**。

- **RT-1**（2022，Google，35M 参数）用 EfficientNet-B3 编码视觉，FiLM 条件化语言，再过一个 Transformer，把 7 自由度的末端执行器动作离散化为 256 个 bin 的 token。它奠定了"视觉编码器 + 语言条件 + 自回归动作头"的基本骨架，但整体还比较"专用"，控制频率仅约 3 Hz。
- **RT-2**（2023，Google）首次把动作 token 直接嵌入一个现成的 VLM（PaLI-X 55B / PaLM-E 12B）的词汇表里，让模型把动作当"另一种语言"来生成。这是 **"VLA" 一词的首创**，标志性意义大于工程意义——它证明了"语言 + 动作"可以在同一个预训练 VLM 里共存。代价是：55B 参数只能跑出约 5 Hz 的离散动作，且离散化会丢失动作空间的连续几何结构。
- **OpenVLA**（2024，Stanford 等）把骨干换成 7B 的 Prismatic，沿用 256 bin 的离散动作 token，用 OXE 大规模数据训练，证明了开源可复现的 VLA 基线。但它在动作表示上并无本质创新，仍是离散化的延续。

**离散化的根本局限**：把一个连续的动作分布强行切成 256 个桶，等于假设动作分布是"分段常数"的。对于需要精细力度控制（插拔、倒水）或存在多模态最优解（抓左边也行、抓右边也行）的任务，这种表示要么精度不够，要么在多个 bin 之间产生虚假的不确定性。

#### 2.1.2 连续动作流的兴起（Octo → π0 → Qwen-VLA / GR00T N1）

对离散化的不满，推动动作表示走向**连续化 + 生成式**：

- **Octo**（2024）引入**扩散动作头**（diffusion action head），直接对连续动作去噪，摆脱了离散 token 的限制，并在多个本体上做预训练。
- **π0**（2024，Physical Intelligence）把这一路线推到主流：PaliGemma 视觉语言骨干 + **flow matching** 动作头，输出高频动作块（action chunk），控制频率可达约 50 Hz。flow matching 相比 DDPM 用更简单的常微分方程路径做生成，训练更稳、采样更少步。
- **Qwen-VLA**（2026，阿里）与 **GR00T N1**（2025，NVIDIA）则共同确立了 **DiT（Diffusion Transformer）+ flow matching** 作为 2026 年的**默认动作表示范式**。Qwen-VLA 用 Qwen3.5-4B 做骨干，DiT 做动作解码，把操作、导航、人类动作、轨迹预测统一成"动作与轨迹预测"（action-and-trajectory prediction）；GR00T N1 的 DiT 动作解码器以约 120 Hz 的高频输出连续动作流。

这一条演进线的本质，是**把动作从"离散分类问题"还原成"连续生成问题"**，从而：

1. 表达多模态动作分布（同一个目标有多种合法抓法）；
2. 支持长时域动作块，减少开环误差累积；
3. 把控制频率从个位数 Hz 提升到几十甚至上百 Hz，让 VLA 真正能驱动真实机器人闭环。

### 2.2 骨干演进：从专用 CNN 到通用 VLM

与动作表示并行演进的，是**承载视觉语言理解的那部分网络（骨干）**。

| 阶段 | 模型 | 骨干 | 参数 | 要点 |
|---|---|---|---|---|
| 专用 | RT-1（2022） | EfficientNet-B3 + Transformer | 35M | 视觉编码器 + FiLM 语言条件，专用设计 |
| VLM 化 | RT-2（2023） | PaLI-X / PaLM-E | 55B / 12B | 动作 token 嵌入 VLM 词汇表，首创 VLA |
| 开源基线 | OpenVLA（2024） | Prismatic | 7B | 256 bin 离散动作，OXE 大规模训练 |
| 轻量高效 | Octo（2024） | 自研 | 93M | 扩散头，跨本体预训练 |
| 生成式 | π0（2024） | PaliGemma | 3B | flow matching 动作头，50Hz |
| 双系统 | GR00T N1 / Helix（2025） | Eagle-2 / VLM 7B | — | 慢规划器 + 快动作策略 |
| 统一 | Qwen-VLA（2026） | Qwen3.5 | 4B | 跨任务/环境/本体统一建模 |

**核心趋势是"分离式设计"**：一个强大的视觉语言底座负责"看懂指令和场景"，一个轻量的动作解码头负责"把理解翻译成动作"。这条线的好处是：底座可以复用海量的视觉语言预训练知识，而动作头只在（相对稀缺的）机器人数据上微调，大幅降低了从零训练的成本。

值得注意的是，这条"分离式"路线与**双系统架构**（见 2.4）在哲学上是同源的——都试图把"慢而深的思考"与"快而浅的反应"解耦。

### 2.3 动作空间统一：跨任务、环境与本体的一个模型

当骨干收敛到通用 VLM 后，下一个要解决的问题是：**不同机器人本体的动作空间完全不同**（单臂 7-DoF、双臂 14-DoF、移动底盘、灵巧手……）。早期做法是"一个本体一个模型"，但 Qwen-VLA 给出了更激进的答案：**一个模型统一所有动作空间**。

Qwen-VLA 的解法包含三件套：

1. **Embodiment-aware prompt**：把本体的动作空间描述（自由度、关节范围、控制频率等）作为文本 prompt 喂给模型，让模型"知道自己在控制哪台机器"。
2. **统一 H×K 动作张量**：把所有本体的动作统一到一个 $H \times K$ 的张量里，$H$ 是动作块长度，$K$ 是一个足够大的统一维度（覆盖最复杂本体的自由度）。
3. **通道掩码（channel mask）**：对每个本体，用掩码遮蔽掉它不用的通道，让模型在一个统一张量上、却针对每个本体输出正确的动作。

这个设计的价值在于：它把"动作空间对齐"从"架构上的硬约束"变成了"输入 prompt 上的软约束"，从而让一个模型在**机器人操作、视觉导航、人类动作与轨迹预测**四类任务上共享参数。这是"通用具身模型"（generalist VLA）真正落地的关键一步。

### 2.4 双系统架构：快慢分离（System 1 / System 2）

当 VLA 要处理长程、多步、需要"思考"的任务时，单一的前馈模型开始捉襟见肘。2025 年，**双系统架构**成为一条独立且重要的分支：

- **GR00T N1**（NVIDIA，2025）：一个**慢的"系统 2"视觉语言规划器**（Eagle-2）负责高层推理、把任务拆解成子目标，一个**快的"系统 1" DiT 动作策略**以约 120 Hz 输出连续动作。两者之间通过隐式潜变量（latent）沟通，实现"边想边动"。
- **Helix**（Figure，2025）：同样的双系统范式——7B VLM 做低频高层规划（~7-9 Hz），80M 的视觉运动策略做高频控制（~200 Hz）。

双系统的意义，是把**"慢思考"（语义理解、任务规划）与"快反应"（实时控制）**在架构上显式分离，从而在长程任务上取得比单系统更好的表现。它和 2.2 的"分离式骨干"、2.1 的"连续动作流"一起，构成了 2025-2026 年 VLA 架构的三大共识。

### 2.5 监督粒度：从 task-level 到 primitive-level

架构侧的另一个被低估的维度，是**监督信号打在哪一层**。

传统 VLA 用的是 **task-level 监督**：整条轨迹对应一个任务标签或一个稀疏奖励。这导致两个问题：模型倾向于"死记整条轨迹"而非"学到可复用的子技能"；长程任务的训练信号极其稀疏。

**PrimitiveVLA**（2026）把监督粒度下钻到了 **primitive-level（动作原语级）**，提出 Primitive-Centric Disassemble & Assemble 范式：

1. **Disassemble（拆解）**：自动把长轨迹拆解成一段段**可复用的动作原语**（motion primitive），例如"接近→抓取→提起→移动→放置"。
2. **MCR 统一表示**：用统一的原语表示（Motion-Centric Representation）编码每个原语，消除不同任务、不同轨迹之间的表面差异。
3. **Planner / Switch 双线程组装**：一个 planner 在高层决定"下一个该用哪个原语"，一个 switch 在底层执行当前原语，两者闭环协作。

![PrimitiveVLA 的原语拆解与组装范式|906](assets/VLA%20模型架构与数据演化%20-%20Survey/figures/04-primitivevla-method.png)

*图 2.2 · PrimitiveVLA 的 Primitive-Centric Disassemble & Assemble：把长轨迹拆成可复用原语，再通过 planner-switch 闭环组装（来源：PrimitiveVLA 论文 Fig.2 method 图）。*

PrimitiveVLA 的价值在于：它证明了**在监督组织层面重构 VLA 的训练 recipe，比单纯换骨干或加数据更能提升数据效率与长程泛化**。这其实是一个"数据问题"用"架构手段"解决的例子——它让我们看到两条线是如何交缠的（详见第 4 章）。

### 2.6 视觉对齐：从显式 grounding 到隐式重建/未来预测

最后一个架构维度，是**视觉观测与任务目标如何对齐**。

早期方法依赖**显式 grounding**：先检测出任务相关的目标物体框，再把框的信息喂给模型。这种方法的代价是：需要额外的检测标注，且泛化到未见物体/场景时容易失效。

2026 年的几篇工作给出了"隐式对齐"的三种不同答案：

- **ReconVLA**（AAAI 2026 杰出论文）：用**目标区域重建**（gaze region 重建）替代显式 grounding。模型在训练时被要求重建人类注视的目标区域，从而学会"隐式地把注意力对齐到任务相关区域"，无需显式检测框。这是"从显式监督到隐式自监督"的典型。
- **GaussianDream**（2026）：在训练阶段引入**当前 3D Gaussian 重建 + 短时未来 3D 演化预测**，让模型学会显式的 3D 几何与世界动态，推理时只保留 prefix（前缀），兼顾了显式几何建模与可控时延。
- **DreamZero**（2026）：用**视频扩散世界模型联合预测"未来视频 + 动作"**，把视觉对齐内化到"想象未来"的过程里。

![ReconVLA 范式对比|1033](assets/VLA%20模型架构与数据演化%20-%20Survey/figures/01-reconvla-paradigm.png)

*图 2.3 · ReconVLA 用"目标区域重建"替代显式 grounding 的范式对比（来源：ReconVLA 论文 Fig.2 paradigm comparison）。*

这三条路线的共同点是：**把"对齐"从需要人工标注的显式任务，转化为可以从数据中自动获得监督的隐式任务**（重建 / 预测）。这既是架构设计，也是数据设计——它再次印证了"架构"与"数据"的边界正在模糊。

## 3. 数据演化：来源、形态、规模与监督信号

### 3.1 真实遥操作数据：规模与标准化的军备竞赛

VLA 的数据故事，起点是**真实机器人遥操作数据**——人类远程操控机器人完成任务，录制下"观测-动作"轨迹对。这类数据最真实、最贵、最稀缺。

| 数据集 | 年份 | 规模 | 本体 | 特点 / 局限 |
|---|---|---|---|---|
| RT-1 | 2022 | 13 万条轨迹 | 单臂 | 首个大规模遥操作数据集，但单一本体 |
| Open X-Embodiment (OXE) | 2023 | 100 万+ 轨迹 | 22 种本体 | 527 技能，跨 60+ 实验室，但高度异构 |
| DROID | 2024 | 7.6 万条轨迹 | Franka 单臂 | 564 场景 / 86 任务，硬件标准化，牺牲规模换一致性 |
| AgiBot World | 2024 | 100 万+ 轨迹 | 双臂 | 217 任务，覆盖双臂 / 工具使用 / 长程 |

这条线的演化逻辑很清晰：

- **RT-1 → OXE**：从"单一实验室单一本体"走向"跨实验室跨本体"的规模化，用**规模**换**泛化**。
- **OXE → DROID**：OXE 的 22 种本体、60+ 实验室带来了海量但**高度异构**的数据（相机角度、控制频率、动作空间都不同），DROID 反其道而行，用**统一的 Franka 单臂硬件标准化**采集，牺牲规模换取**一致性**——证明"数据质量/一致性"有时比"数据规模"更重要。
- **DROID → AgiBot World**：在保持标准化的同时，把规模重新拉回 100 万+，并扩展到**双臂、工具使用、长程任务**等更难的场景。

这是一场"规模 vs 一致性"的反复拉锯，最终收敛到"**既要大规模，又要标准化**"的共识。

### 3.2 合成与仿真数据

真实数据太贵，一个自然的补充是**仿真数据**（在模拟器里无限采集）。仿真数据便宜、可无限生成、可精确标注，但存在著名的 **sim-to-real gap**（仿真到真实的域差距）——在仿真里训好的策略，放到真实世界往往失效。

因此，仿真数据通常不作为独立主线，而是作为**真实数据的补充**，或通过 **sim2real 迁移**（域随机化、域适应）来缩小差距。GigaBrain-0 的 Sim2Real 数据生成（见 3.3）就是把仿真数据"翻译"到真实域的一种尝试。

### 3.3 世界模型生成数据：数据引擎前移

2026 年最值得关注的数据趋势，是世界模型从"辅助模块"前移为"数据引擎"。

GigaBrain-0（2026）系统化地提出了五种世界模型驱动的数据生成方式，全部用于扩充 VLA 训练：

1. Real2Real：在真实数据基础上做扰动/重组，生成新的真实域轨迹；
2. View Transfer：把一段轨迹从一个视角"转移"到另一个视角，做多视角增强；
3. Sim2Real：把仿真数据翻译到真实域；
4. Human Transfer：把人类视频中的动作"迁移"到机器人本体上；
5. Video-Gen：直接生成新的视频轨迹数据。

结合 RGBD 输入与 Embodied CoT（具身思维链），GigaBrain-0 在长程与跨场景泛化上取得了显著提升。

![GigaBrain-0 世界模型数据引擎框架|794](assets/VLA%20模型架构与数据演化%20-%20Survey/figures/06-gigabrain-framework.png)

*图 3.1 · GigaBrain-0 的世界模型数据引擎：Real2Real / View Transfer / Sim2Real / Human Transfer / Video-Gen 五种生成方式（来源：GigaBrain-0 论文 framework 图）。*

GigaBrain-0 的意义在于：它把"数据"从"采集"变成了"生成"。当世界模型足够好，真实机器人的采集成本可以被大幅摊薄——这是一个方向性的信号，指向"无限数据"的未来。

### 3.4 人类视频数据管线：把"人"变成"数据源"

如果世界模型生成数据是"合成"路线，那么**人类视频**就是"半真实"路线——人类活动视频天然大量存在于互联网上，且天然包含"手眼协调、操作物体"的丰富信息。

**VITRA**（2026）是这条路线最系统的工作，它提出了一条**三阶段自动管线**，把无标注的真实人类活动视频转成与机器人操控对齐的 VLA 预训练数据：

1. **3D Motion Labeling**：用 HaWoR / MegaSAM / MoGe-2 等工具，从 2D 人类视频中恢复 3D 手部与物体运动；
2. **Atomic Action Segmentation**：把连续的人类活动切分成原子动作片段；
3. **Instruction Labeling**：为每个原子动作自动生成语言指令。

VITRA 的关键创新是**102 维显式 3D 动作表示**——不满足于 2D 关键点，而是显式建模 3D 手部姿态与物体 6D 位姿，从而让人类视频中的"动作"能与机器人的动作空间对齐。实验证明，用这些数据预训练的 VLA，在真实机器人 seen / unseen 场景中的泛化能力都显著提升。

![VITRA 三阶段人类视频管线|887](assets/VLA%20模型架构与数据演化%20-%20Survey/figures/02-vitra-pipeline.png)

*图 3.2 · VITRA 的三阶段管线：3D 运动标注 → 原子动作切分 → 指令标注，把无标注人类视频转成 VLA 预训练数据（来源：VITRA 论文 pipeline 图）。*

**DreamZero**（2026）则从另一个角度利用人类视频：它的 WAM（World Action Model）用视频扩散模型（Wan2.1-I2V-14B）联合预测"未来视频 + 动作"，并在推理时用 **KV cache 回写真实观测**实现约 7 Hz 的闭环控制。更重要的是，它在跨 embodiment 迁移上验证了"人类视频 → 机器人"的可行性（见其 Fig.11 embodiment transfer）。

这两条工作共同指向一个结论：**人类视频是 VLA 数据中最被低估、也最有潜力的来源**——它近乎无限、天然丰富、且与机器人操控存在结构上的相似性。

### 3.5 训练期密集监督：把"世界"变成监督信号

数据演化的最后一层，是**训练期间能否获得比"动作标签"更密集的监督信号**。

**GaussianDream**（2026）给出了一个漂亮的答案：在 VLA 训练阶段，额外引入**当前 3D Gaussian 重建**与**短时未来 3D 演化预测**作为训练目标，相当于让模型在学动作的同时，也学会了"当前世界的 3D 结构"和"世界如何演化"。这些信号（如 pseudo depth、3D flow）可以在无额外人工标注的情况下，从 RGB-D 数据中自动获得，因此是"免费的密集监督"。推理时，只需保留 prefix，不增加额外时延。

![GaussianDream 范式对比](assets/VLA%20模型架构与数据演化%20-%20Survey/figures/07-gaussiandream-paradigm.png)

*图 3.3 · GaussianDream 在训练期引入 3D Gaussian 重建 + 未来演化预测作为密集监督，推理仅保留 prefix（来源：GaussianDream 论文 Fig.1 paradigm comparison）。*

这条线的启示是：**数据不仅是"样本"，更是"监督信号的密度"**。同样一批轨迹，如果能从中挖掘出更密集的监督（3D 结构、未来状态、子目标），模型的训练效率会显著提升——这与 2.5 的 primitive-level 监督是同一个道理。

## 4. 两条线的交汇：架构与数据如何互相塑造

读完两条线，最深的体会是：**架构决策和数据决策从来不是独立的**。它们之间有几组清晰的因果链条：

1. **连续动作表示 → 需要更多、更连续的数据**。当动作从"256 个离散 bin"变成"连续流"，模型对数据的要求也变了：离散 token 可以用稀疏标签训练，但连续流（diffusion / flow matching）需要更密集、更连续的动作监督。这反过来推动了 OXE、AgiBot World 的规模化，以及世界模型生成数据的兴起。
2. **数据形态 → 决定动作表示的对齐方式**。人类视频天然没有机器人动作标签，VITRA 才需要发明"102 维 3D 动作表示"来把人类动作对齐到机器人空间；世界模型生成的数据天然带有未来状态，DreamZero 才能用"未来视频 + 动作"联合预测。**数据的形态，约束了架构能采用的表示。**
3. **数据稀缺 → 倒逼监督粒度下钻**。真实遥操作数据永远稀缺，PrimitiveVLA 的 primitive-level 监督、GaussianDream 的 3D 密集监督，本质上都是在"给定同样数据量"的前提下，榨出更多训练信号。**这是"数据问题"用"架构/训练手段"解决的典型。**
4. **架构的视觉对齐需求 → 催生新的数据监督信号**。ReconVLA 需要"人类注视区域"、GaussianDream 需要"3D 结构"、DreamZero 需要"未来帧"，这些监督信号都不是传统的动作标签，而是从数据中自动挖掘或由世界模型生成的新信号。**架构想要什么，数据就得提供什么。**

一言以蔽之：**VLA 的进化史，就是"架构能表达什么"与"数据能提供什么"之间不断互相拉高上限的历史。**

## 5. 局限与评价

### 5.1 当前范式的普遍局限

1. **真实世界闭环的稳定性和安全性仍未解决**。即使 Qwen-VLA / GR00T N1 把控制频率提到几十上百 Hz，真实机器人在长程、接触密集、动态干扰任务上的成功率仍与人类差距巨大，且缺乏安全的失败恢复机制。
2. **"数据无限"仍是纸面假设**。世界模型生成数据（GigaBrain-0）、人类视频（VITRA）都还处在"能提升泛化"的阶段，尚未证明能**替代**真实遥操作数据；生成数据的质量上限受限于世界模型本身，存在"垃圾进垃圾出"的风险。
3. **评测碎片化**。OXE、DROID、AgiBot World 的评测协议、任务集、成功标准各不相同，导致不同工作之间的数字难以直接比较，很多"刷新 SOTA"的结论需要打折看待。
4. **计算成本与部署门槛**。55B（RT-2）、7B（OpenVLA）甚至双系统（GR00T N1）的模型，在边缘机器人上的部署仍是巨大挑战，多数工作靠云推理或高端 GPU，离"上机量产"还有距离。

### 5.2 对本综述覆盖论文的独立判断

- **ReconVLA**：方法启发性最高，"隐式对齐"代表方向正确，但"目标区域重建"的监督信号本身依赖人类注视数据，规模化仍有疑问。
- **VITRA**：数据管线工程最扎实，"人类视频 → VLA"是最有潜力的数据路线，但 102 维 3D 动作表示的获取链路长、易受重建误差影响。
- **DreamZero**：把世界模型与策略在"视频扩散"框架下统一，思想干净，但 7 Hz 的闭环频率对精细操作仍偏慢，且依赖大规模视频扩散模型的计算。
- **PrimitiveVLA**："监督粒度"是当前被低估、但可能带来数据效率质变的方向，值得重点跟踪；primitive 自动拆解的鲁棒性是主要风险。
- **Qwen-VLA**："统一动作空间"是通用具身模型的必经之路，工程价值高；但跨本体统一张量的极限在哪（能统一多少种本体？）尚未被充分验证。
- **GigaBrain-0**：方向性信号强（数据引擎前移），但五种生成方式的贡献消融、生成数据的质量上限仍需更多独立验证。
- **GaussianDream**：训练期 3D 密集监督 + 推理保留 prefix 的设计很优雅，但 3D Gaussian 重建的引入是否带来隐式的"数据/模型"耦合成本，值得进一步拆解。

## 6. 个人判断与遗留问题

**个人判断**：VLA 的下一个突破口，大概率不在"更大的骨干"或"更多的数据"上，而在**"更聪明的监督信号"**——即 PrimitiveVLA 的 primitive-level、GaussianDream 的 3D 密集监督、DreamZero 的未来预测所代表的"从有限数据里榨出更多结构"。同时，"世界模型 = 数据引擎"（GigaBrain-0）和"人类视频 = 预训练语料"（VITRA）两条路线会继续合流，最终可能让 VLA 摆脱对昂贵遥操作数据的依赖。

**遗留问题（留给后续跟踪）**：

1. 世界模型生成数据能否在**闭环**中自举（用生成数据训练的策略，再反过来改进世界模型），形成"数据飞轮"？
2. 跨本体统一动作空间（Qwen-VLA）的**上限**在哪——能否统一到灵巧手、移动双臂、甚至人形机器人？
3. 双系统架构（GR00T N1 / Helix）与单系统统一模型（Qwen-VLA）最终谁会赢，还是会在不同任务粒度上共存？
4. 人类视频（VITRA）与仿真/世界模型（GigaBrain-0）的**数据组合比例**如何最优，是否存在可预测的 scaling law？
5. 隐式视觉对齐（ReconVLA / DreamZero / GaussianDream）能否最终**完全取代**显式 grounding？

**第 7 章新增的遗留问题**（2026 下半年的范式修正带来的新追问）：

6. **离散扩散与连续 flow matching 是否会融合**？MMaDA-VLA（离散扩散）和 π0 / Qwen-VLA（连续 flow matching）现在是并行 SOTA，但二者各有局限：离散扩散在长程一致性上更优雅，但离散化损失动作精度；连续流对精细控制更友好，但外挂世界模型会带来信息损失。**未来 1–2 年最值得关注的架构问题是"外层离散扩散 + 内层连续 flow matching"这类混合范式**。
7. **WAM 路线（Motus / MotuBrain / WorldVLA）能否在长程任务上真正取代 VLM 作为通用底座**？当前 WAM 在 50 任务级别的仿真上验证了 scaling law，但**真实世界的长程 + 接触密集 + 动态干扰**仍是空白。如果 WAM 路线成功，"VLA"这个词本身就可能演变为"WAM"。
8. **"视觉空间表征"会成为 VLA 的独立模块吗**？CVPR 2026 冠军奖证明 4K 参数就能撬动 38.6 个百分点的视角鲁棒性——这暗示视觉空间表征校准（FTM / FLA 类）可能发展成类似"LoRA 之于 LLM"那样的标配工具。AtlasVLA 则暗示 4D 空间记忆可能成为独立模块。
9. **具身推理（Embodied Reasoning）作为独立云端服务，能否与本地动作头形成"云脑 + 本地反射"的标准化分层**？Gemini Robotics-ER + 各种本地 VLA 的组合在 2026.4 落地 Boston Dynamics Spot，这是首个工业化样本——它的成败将决定未来 VLA 是"端到端大一统"还是"云脑 + 本地反射"的二段式。

## 7. 2026 新范式：动作表示的第二次革命与世界模型的回归

第 1–4 章的结论是 2026 年 4–8 月的"快照"，到 2026 年 8–10 月时，已经被一波集中涌现的新工作修正。本章按四条新路线展开，配 4 张原文 pipeline 图，并把前文哪些判断需要修正、哪些判断仍然成立讲清楚。

### 7.1 动作表示的第二次革命：离散扩散原生 VLA

#### 7.1.1 范式动机：连续 flow matching 解决了什么、又留下了什么

第 2.1 节给出了"动作表示的第一次革命"——从 RT-2 / OpenVLA 的离散 token 走向 Octo / π0 / Qwen-VLA / GR00T N1 的连续 flow matching 与 DiT。它解决了三个问题：多模态动作分布、长时域动作块、与高频控制解耦。但也留下三个新问题：

1. **架构冗余**：主流方案仍是"分层架构"——视觉编码器 + 语言模型 + 连续动作解码头三层堆叠，模块间信息流未充分融合；
2. **误差累积（这次在 chunk 内）**：连续 flow matching 内部仍是迭代去噪，长 chunk 内的去噪误差仍会沿时间维累积；
3. **缺乏环境动态的内生建模**：连续动作头不会预测"动作执行后世界会变成什么样"，要理解环境动态，仍需外挂一个世界模型（见 7.2）。

这三个问题共同催生了 **"离散扩散原生 VLA"** 的反潮：把动作**重新离散化**回到 token 空间，但用"**离散扩散（masked token 去噪）**"而非"自回归"来生成——一举把"多模态语言"与"连续控制"统一进**单一离散 token 词汇表 + 单一主干网络 + 单一去噪目标**。

#### 7.1.2 MMaDA-VLA：原生预训练的大扩散 VLA

**MMaDA-VLA**（arXiv:2603.25406，西湖大学 + 浙江大学 + 港科大（广州） + 华为 Celia Team + OpenHelix，2026.3）把这套思路做到极致，给出了**首个原生预训练的大型离散扩散 VLA**。它的方法可拆成四件套：

1. **统一离散 token 空间**：文本用 LLaDA tokenizer、视觉图像用 Show-o 的 MAGVIT-v2 量化器、连续动作按维度离散化为 256 个区间——三者共享一个 $V$ 大小的词表，从根本上消除了跨模态信息传递的障碍。
2. **掩码 token 去噪作为单一训练目标**：把所有模态（语言、图像、动作）的 token 拼接成一个序列，按余弦调度随机 mask 一部分，模型从被 mask 的"噪声状态"恢复完整序列。损失函数是标准的 masked token 预测损失：

$$
\mathcal{L} = -\mathbb{E}_{x, t}\left[\sum_{i \in \mathcal{M}} \log p_\theta(x_i \mid x_{\setminus \mathcal{M}})\right]
$$

其中 $\mathcal{M}$ 是被 mask 的位置集合，$x_{\setminus \mathcal{M}}$ 是未 mask 的上下文。

3. **混合注意力机制**：模态内（intra-modal）用双向全注意力，让同一模态内的 token 充分相互感知；模态间（inter-modal）用因果注意力，让语言、当前观测、目标观测、动作之间保持稳定的因果依赖。这种设计**解耦了"目标图像生成"与"动作生成"两个目标**，让模型既能在迭代去噪中共享中间特征，又不会让两个目标互相干扰。
4. **并行生成未来目标观测 + 动作块**：推理时同时输出**未来目标观测**（即"执行完动作后，环境应该变成什么样"）与**动作块**。这等价于把世界模型的"未来预测"内化进 VLA 的单一去噪过程——**不再需要外挂世界模型，也能让动作"锚定"在未来视觉预期上**。

为了满足机器人实时性，MMaDA-VLA 还引入了**免训练缓存机制**：指令 token 全程缓存，生成 token 每 $k$ 步仅刷新与缓存 Value 向量余弦相似度最低的若干 token。

![MMaDA-VLA 框架结构与训练管线](assets/VLA%20模型架构与数据演化%20-%20Survey/figures/08-mmadavla-architecture.png)

*图 7.1 · MMaDA-VLA 的统一离散 token 空间 + 掩码去噪 + 混合注意力 + 并行生成未来观测与动作块的完整 pipeline（来源：MMaDA-VLA 论文 Fig.2 architecture）。*

#### 7.1.3 关键结果与对比

MMaDA-VLA 在两个最严苛的机器人操控基准上同步刷新 SOTA：

- **LIBERO**：4 个任务套件（spatial / object / goal / long）全部第一，**平均成功率 98.0%**，超过 π0 (94.2%)、OpenVLA-OFT (97.1%)、VLA-Adapter (97.3%)、π0.5 (96.8%)、MemoryVLA (96.5%) 等所有此前方法。
- **CALVIN (ABC→D 泛化)**：平均任务完成长度 **4.78 / 5**，超过 OpenVLA-OFT (4.42)、π0 (3.92)、RoboVLMs (4.25)、VLA-Adapter (4.42) 等。
- **真实世界**：在 AgileX Piper 机械臂的 4 类任务（简单抓放、精确堆叠、复杂收纳、长程整理）上，**单类任务成功率 83.3%–93.3%**，全面超过 GR00T N1.6 (64.2%)、DOVLA、UniVLA (89.2%)。

与之并行的还有同路线的几项工作：

- **Discrete Diffusion VLA**（ICML 2026，SJTU）：提出"先解决高置信动作、再回头重掩码纠错"的自适应解码顺序，几乎不损失 VLM 先验（语言退化仅 0.8%）。
- **UD-VLA / Unified Diffusion VLA**（arXiv:2511.01718）：把理解、生成、动作放进同一条联合去噪轨迹，推理比自回归快 4×。
- **LLaDA-VLA、MemoryVLA、VLA-Adapter、OpenVLA-OFT**：这一波是"扩散化 + 动作块 + 高效适配"的标准 SOTA 配方。

**与第 2.1 节结论的对话**：前文说"连续动作流是默认范式"，这个判断在 2026 年仍然成立——π0 / Qwen-VLA / GR00T N1 仍是工业界主流。但**学术 SOTA 已经在 2026 年下半年被离散扩散反超**。这两条路线现在是**并行 SOTA**，不是谁替代谁：连续 flow matching 工程上更稳、训练更熟；离散扩散在长程一致性、与未来视觉联合生成上更优雅、可解释性更强。**未来 1–2 年的关键问题是这两条路线是否会在同一架构内融合（例如"外层离散扩散 + 内层连续 flow matching"）**。

### 7.2 世界模型回归：从"数据引擎"升级为"统一具身底座"

#### 7.2.1 范式跃迁：WAM = WM + Action

第 3.3 节把世界模型定位为"数据引擎"（GigaBrain-0）。但 2025 年底到 2026 年，世界模型经历了一次**身份升级**——它不再只是给 VLA 生成训练数据的"外挂模块"，而是要**取代 VLM 成为统一的具身底座**。这个新范式叫 **WAM（World Action Model）** 或 **VLA-WM 统一架构**，核心主张是：**视频、动作、语言必须在同一个模型里联合训练、联合推理**，因为"动作"和"对未来的预测"在物理上不可分。

#### 7.2.2 Motus：首个统一潜动作世界动作模型

Motus（arXiv:2512.13030，生数科技 + 清华，2025.12）是这个新范式最具标志性的早期工作。它把"理解（VLM）/ 视频生成（VGM）/ 动作生成（Action Expert）"三个已有高性能基座，用 Mixture-of-Transformers（MoT）架构 拼成一个统一模型，再用 UniDiffuser-style scheduler 在五种模式间灵活切换：

| 模式                            | 作用                 | 推理含义         |
| ----------------------------- | ------------------ | ------------ |
| World Model                   | 给定历史观测 + 动作，预测未来视频 | "做完会怎样"      |
| Vision-Language-Action (VLA)  | 给定当前观测 + 指令，输出动作   | "现在该做什么"     |
| Inverse Dynamics Model (IDM)  | 给定前后两帧，推断动作        | "这两帧之间发生了什么" |
| Video Generation Model (VGM)  | 纯视频生成              | "想象可能的未来"    |
| Video-Action Joint Prediction | 同时预测未来视频 + 动作      | "看一步、动一步"    |

架构上有三个关键设计：

1. Tri-model Joint Attention（中间桥接）：Transformer 层的中间 50% 层做"视频 + 动作"联合注意力（称为 H-Bridge），实现跨模态语义对齐；底部与顶部各 25% 层解耦，分别处理模态内特征。这样既维持了模态内表征能力，又显著降低了密集跨模态注意力的计算开销。
2. Latent Action VAE（基于光流的潜动作）：从无标签互联网视频和人类视频中用光流（DPFlow）提取"潜动作"（latent action）$z_t$，再用 VAE 压缩——这样模型可以在没有真实动作标签的互联网视频上预训练"动作先验"，极大扩展了可用数据。
3. 三阶段训练 + 六层数据金字塔：
   - Stage 1（VGM 训练）：仅训视频分支，使用 Level 1–3 数据（互联网视频、自我中心视频、合成数据）；
   - Stage 2（Motus 预训练）：冻结视频分支，训动作分支 + 联合注意力，使用 Level 2–5 数据；
   - Stage 3（Motus SFT）：全模型微调，使用 Level 6（目标机器人轨迹）。

六层数据金字塔从 Level 1（互联网视频）到 Level 6（目标机器人轨迹），任务相关性与数据质量逐级提升。

![Motus 的 MoT 统一架构|920](assets/VLA%20模型架构与数据演化%20-%20Survey/figures/09-motus-architecture.png)

*图 7.2 · Motus 的三专家 MoT 架构：Video Gen. Model + Action Expert + Und. Expert 通过 Tri-model Joint Attention（中间 H-Bridge 桥接）协作，输出未来视频 + 动作（来源：Motus 论文 Fig.1 Motus Architecture）。*

#### 7.2.3 关键结果与意义

Motus 的实验给出了两个颠覆性信号：

- RoboTwin 2.0 50 任务平均 87.02%：单模型在 50 项双臂操作任务上比 π0.5 提升约 +45 个百分点，比 X-VLA 提升 +15 个百分点。
- 首次画出具身模型的 scaling law：随着训练任务数和数据量增加，平均成功率持续提升，且扩展趋势显著优于传统 VLA 基线——这是"具身智能的 GPT-2 时刻"，第一次实证证明具身模型遵循可预测的 scaling law。

与之并行的还有几条相关工作（也常被归为 WAM 路线）：

- MotuBrain（arXiv:2604.27792，2026.4）：Motus 的后续工业版，在 RoboTwin 2.0 clean 95.8% / randomized 96.1%，配合系统化加速栈实现 54.4× 端到端加速（4.90s → 0.09s），推理频率 11 Hz，首次让大规模 WAM 实时具身部署成为可能。
- WorldVLA（阿里）：把 VLA 和世界模型放进单一自回归框架，用 attention mask 缓解误差传播。
- Cosmos Policy（NVIDIA）：基于 Cosmos 世界基础模型的视频扩散 + 动作联合去噪（co-diffusion），用 Latent Frame 把动作注入视频序列。
- DreamVLA、GEVRM、Seer：把世界模型生成数据与 VLA 联合训练，证明 WAM 路线在 LIBERO / CALVIN 等基准上的有效性。

与第 3.3 节结论的对话：前文说"世界模型是数据引擎"，这个判断在 2026 年初成立，但到 2026 年下半年已经被自己升级了——世界模型现在同时是数据引擎（生成训练数据）和统一底座（取代 VLM 成为模型主体）。这是 VLA 范式最深刻的一次重构：从"VLM + 动作头"走向"WAM = 视频 + 动作 + 理解的统一生成模型"。

### 7.3 空间与记忆建模：被低估的新主战场

第 1–4 章反复强调"动作表示、骨干、监督粒度、视觉对齐"四个维度。但 2026 年的两个独立工作——一个来自学术顶会（CVPR 2026 冠军奖），一个来自中科院自动化所——几乎同时指出：**VLA 的失败往往不是因为"不懂物理"，而是因为"看到的空间变形了"，且"记不住过去的任务进度"**。这一维度是前文严重低估的新主战场。

#### 7.3.1 空间-物理可分离性：用 4K 参数撬动 38.6 个百分点

**"VLA Models Are More Generalizable Than You Think: Revisiting Physical and Spatial Modeling"**（CVPR 2026 Compute Transparency Champion Award，arXiv:2512.02902，中山大学 + X-Era AI Lab）给出了一个干净而反直觉的结论：

> 把 VLA 拆成"**空间建模**（visual encoder 负责，建模物体位置/朝向/遮挡/接触）"和"**物理建模**（VLM + 动作专家负责，建模任务语义/动作历史/物理因果）"两块；新视角下的性能下降，**根因是空间表征的错位，而非物理推理能力的缺失**。

证明这个判断的实验是**两个 one-shot 轻量适配器**：

1. **FTM（Feature Token Modulation）**：仅学习两个全局向量 $\gamma, \beta$，对视觉 token 做仿射变换 $\hat{F} = (1+\gamma) \odot F + \beta$。**仅 4K 参数**，把 LIBERO 新视角成功率从 **48.5% 拉到 87.1%**。
2. **FLA（Feature Linear Adaptation）**：在 ViT 编码器的线性层加 LoRA 式低秩更新 $W' = W + BA$，**仅 4.7M 参数**，把 LIBERO 新视角成功率进一步拉到 **90.8%**，**与 LoRA 微调（467M 参数）的 90.3% 持平，但参数效率高 99 倍**。

**核心数字**：4K 参数换来 **+38.6 个百分点**——这是"用参数效率换泛化能力"的极致示范。

![VLA 空间-物理建模的五种适配方案对比](assets/VLA%20模型架构与数据演化%20-%20Survey/figures/11-spatial-physical-solution.png)

*图 7.3 · 五种 VLA 视觉空间适配方案对比：(a) LoRA 微调、(b) 替换视觉骨干、(c) Prompt Learning 是已有方案；(d) FTM（4K 参数 γ, β 仿射）、(e) FLA（4.7M 参数低秩更新）是本文方案。火焰🔥表示哪种模块被修改（来源：CVPR 2026 论文 Fig.3 solution）。*

#### 7.3.2 AtlasVLA：双记忆驱动的单腕相机方案

**AtlasVLA**（arXiv:2608.06729，中科院自动化所，2026.8）从另一个角度解决"单腕相机 + 长程任务"的双遗忘问题。它的核心创新是**双记忆架构**，把"反应式操作"升级为"主动推理"：

1. **4D 持久世界状态记忆（Persistent World State Memory）**：把瞬时 2D 观测通过 DAV3 视觉编码 + 空间反投影，提升成**全局更新的体素哈希 4D 空间状态**。这把"腕部相机看到的一帧"升级为"机器人对整个工作空间的 4D 持久认知"，从而解决**感知遗忘**（物体移出视野后仍能记住其位置）。
2. **ego 工作状态记忆（Ego-Working State Memory）**：跟踪历史 ego 状态与任务进度（"我现在做到哪一步了"），通过 Ego-Working Consolidation + Time Positional Embedding 维护一个 ego memory bank。这解决**进度遗忘**（多步执行中不会忘记前几步做了什么）。
3. **World-Ego-Guided Action DiT（×L 层）**：把两个记忆 bank 分别通过 Ego-Guided / World-Guided Retrieval 取出上下文，作为 DiT 的 Key-Value 输入，生成动作。

![AtlasVLA 的 4D 持久世界-ego 双记忆架构|1055](assets/VLA%20模型架构与数据演化%20-%20Survey/figures/10-atlasvla-method.png)

*图 7.4 · AtlasVLA 的双记忆驱动 DiT：Persistent Wrist Observation → Instantaneous World State Construction → 4D Persistent World State Memory + Ego-Working State Memory → 驱动 World-Ego-Guided Action DiT 生成动作（来源：AtlasVLA 论文 method 图）。*

**关键结果**：仅用单腕相机，在 LIBERO-Long 上**绝对成功率提升 9.4%**，在真实长程任务上**提升 17.5%**，**超过多视角基线**——这是"用更聪明的记忆弥补硬件视角缺失"的强证据。

**与前文判断的对话**：第 1 章列了 5 个"被低估"的方向（监督粒度、视觉对齐、动作空间统一……），但**漏掉了"空间与记忆"**。AtlasVLA 与 CVPR 2026 冠军奖同时出现，说明这一维度不是个别工作，而是 VLA 整个领域正在转向的新主战场。**未来 1–2 年，"空间-记忆"很可能与"动作表示"并列为 VLA 架构的两大核心议题**。

### 7.4 具身推理与工程基线

除上述三大主线外，2026 年还出现了两类值得关注的进展：

#### 7.4.1 具身推理（Embodied Reasoning）成为独立品类

- **Gemini Robotics / Gemini Robotics-ER**（Google DeepMind）：把"具身推理"从 VLM 里拎出来作为一个独立可 scale 的模型——**物理常识**（知道玻璃瓶易碎、要先把食物分装才能端盘子）、**开词汇检测**（不再为每个仓库单独训检测模型）、**长程时序推理**（把 30 秒视频 token 化，判断"这次抓取到底滑没滑"）。ER 1.6 已上 Gemini 3 Flash 骨干，2026.4 起落地 Boston Dynamics Spot。
- **CoT-VLA**、**HiRT**、**Pi0.5** 等：把"思维链"显式引入 VLA 推理过程，让模型在生成动作前先生成对任务的高层描述。

这条线的信号是：**"理解世界"与"控制动作"正在被拆成两个可分别 scale 的模型**——这与第 2.4 节的双系统（System 1 / System 2）殊途同归，但更激进：双系统仍把两部分装在同一个机器人系统里，而具身推理派直接把"推理模型"和"动作模型"做成可独立升级的云端服务。

#### 7.4.2 工程级新基线

- **FAST tokenization**（π0 提出，2024；OpenVLA-OFT、CogACT、π0.5 全在用）：对动作块做 **DCT 变换 + BPE 词表压缩**。原来 50 步 × 7 DoF = 350 个动作 token 压缩到约 30 个，**序列长度缩短约 10×**，推理延迟显著下降，已成为 2026 年事实标准。
- **FAST++ / OpenVLA-OFT** 等：把 FAST 与并行解码、高效 attention 进一步整合，把 VLA 推理延迟从秒级压到百毫秒级。
- **OmniVLA**（ICRA 2026）：把红外 / 毫米波 / 声学等非视觉传感器统一成"传感器掩码图像"叠在 RGB 上，超感知任务 84% vs 纯 RGB 25%，打破了"VLA 只能看 RGB"的限制。
- **MemoryVLA、Flow VLA、UP-VLA**：分别在长程记忆、连续流式动作、跨任务策略整合上推进，构成了 2026 年 VLA 的"SOTA 配方库"。

### 7.5 与前 4 章的对话：哪些判断需要修正、哪些仍然成立

把第 7 章和第 1–4 章放在一起，本综述的判断需要做以下修正：

| 前文判断（1–4 章） | 2026 下半年的修正 | 触发的新工作 |
|---|---|---|
| 连续 flow matching 是动作表示的"终点" | 连续流与**离散扩散**并行 SOTA，连续不是终点 | MMaDA-VLA、Discrete Diffusion VLA、UD-VLA |
| 世界模型只是"数据引擎" | 世界模型升级为**统一具身底座（WAM）** | Motus、MotuBrain、WorldVLA、Cosmos Policy |
| VLA 的失败主要是"数据不够"或"骨干不够大" | 根因之一是"**视觉空间表征错位**"和"**任务进度遗忘**" | CVPR 2026 冠军奖、AtlasVLA |
| "理解"和"控制"必须在同一个 VLA 模型里 | 两者正在被拆为可独立 scale 的"具身推理 + 动作模型" | Gemini Robotics-ER、CoT-VLA |

但有几条核心判断**仍然成立**：

1. **架构与数据两条线互相塑造、螺旋上升**——这条主线没变，Motus 用"数据金字塔"和"潜动作预训练"再次验证了它；
2. **监督粒度从 task-level 下钻到 primitive-level 是数据效率的质变路径**——PrimitiveVLA 的判断仍成立，Motus 的 Stage 2/3 训练策略实际上在更宏观尺度上再次验证了它；
3. **视觉对齐从显式 grounding 走向隐式重建/预测**——ReconVLA / GaussianDream / DreamZero 的判断仍成立，AtlasVLA 的"持久世界状态"是这条线的空间-时间扩展；
4. **跨本体统一动作空间是通用具身模型的必经之路**——Qwen-VLA 的判断仍成立，Motus 的"跨具身潜动作"在更激进的意义上再次验证了它（连人类视频都成了预训练数据）。

**最终结论**：VLA 的 2026 故事，是"**连续与离散并行 + WAM 统一底座 + 空间-记忆主战场 + 推理-动作解耦**"四条新路线的合流。它们不是对前文结论的颠覆，而是把前文结论推向了更深的层次——VLA 不再是"VLM + 动作头"的简单范式，而是一个**多模态生成、空间-时间记忆、显式-隐式推理、连续-离散动作表示**深度耦合的复杂系统。

## 8. 系列脉络：把单篇论文放回它的家族

前面七章以「问题」为主线，把不同机构的论文打散重组进「架构」与「数据」两条线。但 VLA 领域还有一条同样重要的线索——**系列（lineage）**：同一个机构或团队沿一条技术主轴**连续迭代**，每一代都站在上一代肩上，有时甚至「自己推翻自己」。读懂系列，才能看清「为什么这个团队在那一刻做出那个选择」。本章按机构/团队，把前文散落的单篇论文重新归位到它们所属的系列，并补充每个系列里前文未展开的代际节点。

### 8.0 系列总览与「人员流动」这条暗线

在展开各系列前，先点破一条被严重低估的暗线：**VLA 的系列演进，背后是同一批人从闭源走向开源、从大厂走向创业**。

- **Chelsea Finn**：RT 系列作者之一，Physical Intelligence（PI）联合创始人，同时是 OpenVLA 与 Octo 的作者之一。
- **Sergey Levine**：RT-1/RT-2 参与者的导师，PI 联合创始人兼首席科学家，Octo / OpenVLA 作者。
- **Karol Hausman**：RT-1 / RT-2 / SayCan 的核心作者，PI 联合创始人。
- **Brian Ichter**：Google Brain，RT 系列参与者，PI 联合创始人。

这批人 2024 年初离开 Google 创办 Physical Intelligence，把 RT 系列的「视觉语言 + 动作」血脉，带到了 π 系列和开源 VLA 社区。**所以 RT 系列和 π 系列不是简单的竞争关系，而是同一技术血脉的两段**——一段闭源（Google），一段开源创业（PI）。

| 系列 | 主导机构 | 技术主轴 | 关键代际 |
|---|---|---|---|
| RT / Gemini Robotics | Google DeepMind | 从专用控制到原生具身大脑 | RT-1 → RT-2 → RT-X → Gemini Robotics → ER 2 |
| π 系列 | Physical Intelligence | flow matching 动作底座 → 可操控大脑 | π0 → π0.5 → π0.6 → π0.7 |
| GR00T 系列 | NVIDIA | 双系统人形基座 + 合成数据引擎 | N1 → N1.5 → N1.6 → N1.7 |
| OpenVLA / Octo | 学术界（Finn / Levine 团队） | 开源可复现 VLA 基线 | OpenVLA → OpenVLA-OFT；Octo |
| WAM 系列 | 生数 / 阿里 / 英伟达 | 世界模型升级为统一具身底座 | GigaBrain-0 → DreamZero → Motus → MotuBrain |
| 离散扩散系列 | 西湖大学等 | 离散扩散原生 VLA | MMaDA-VLA → Discrete Diffusion VLA → UD-VLA |
| 数据系列 | 多机构 | 规模与标准化的军备竞赛 | RT-1 数据 → OXE → DROID → AgiBot World |

### 8.1 Google Robotics Transformer（RT）系列：从专用控制到原生具身大脑

RT 系列是 VLA 的「母系列」——前文 2.1 提到的离散动作 token、2.2 的骨干演进，几乎全部发源于这条线。它最完整的代际链是：

| 时间 | 模型 | 关键变化 |
|---|---|---|
| 2022.12 | **RT-1** | 35M，EfficientNet-B3 + FiLM + Transformer，3 Hz，首次把 Transformer 用于大规模真实机器人控制 |
| 2023.3 | **PaLM-E** | 562B 具身多模态大模型，把 LLM 的推理能力引入物理世界（但动作生成仍较弱） |
| 2023.7 | **RT-2** | PaLI-X 55B，**首创 VLA**，动作 token 嵌入 VLM 词表，零样本推理 |
| 2023.10 | **RT-X**（RT-1-X / RT-2-X） | 用 OXE 跨 22 本体训练，RT-1-X 平均成功率较 RT-1 **高 50%**，RT-2-X 泛化能力约为 RT-2 的 **3 倍** |
| 2024.1 | **AutoRT / SARA-RT / RT-Trajectory** | 三连发：自动采集 7.7 万轨迹 / 注意力稀疏化提速 14% / 2D 轨迹草图监督提升长程任务 25% |
| 2024.3 | **RT-H** | 把复杂任务先分解成语言子指令，再逐条转成动作 |
| 2025.3 | **Gemini Robotics** | 放弃 RT 编号，直接以 Gemini 2.0 为骨干做原生具身化，RT 系列「毕业」 |

这条链的启示是：**RT 系列的每一次迭代，都在攻克通用机器人落地的一个具体瓶颈**——RT-1 验证 Transformer 可行性，PaLM-E 打通数字知识到物理世界的对齐，RT-2 确立 VLA 端到端范式，RT-X 破解跨本体数据共享，2024 工具链破解数据效率与实时部署，Gemini Robotics 完成「大模型原生具身化」的收口。它是一条教科书式的「模型创新 → 数据支撑 → 工程落地」闭环。

### 8.2 Gemini Robotics 系列：VLA 与「具身推理」的分叉

Gemini Robotics 是 RT 系列的继承者，但它做了一个 RT 系列没有的结构性决定——**把「VLA」和「具身推理（Embodied Reasoning, ER）」拆成两条可独立演进的支线**（这正是前文 7.4.1 说的「理解与控制解耦」的工业化落地）：

| 时间 | 模型 | 关键变化 |
|---|---|---|
| 2025.3 | **Gemini Robotics / ER** | VLA 直接输出动作；ER 专注感知 + 推理 + 高层规划，输出指令喂给下游控制器 |
| 2025.6 | **Gemini Robotics On-Device** | 首个面向端侧部署的 VLA，配 MuJoCo 集成 |
| 2025.9 | **Gemini Robotics 1.5 / ER 1.5** | 1.5 引入 **Motion Transfer（MT）** 跨本体运动迁移 + 动作预测中穿插自然语言推理 |
| 2026.4 | **Gemini Robotics-ER 1.6** | 空间推理 + 多视角理解 + **工业仪表读取**（配合 Agentic Vision，成功率 23%→93%），2026.4 落地 Boston Dynamics Spot |
| 2026.7 | **Gemini Robotics 2 / ER 2** | ER 2 通过 Gemini API 公开，可分析连续视频流跟踪任务进度 |

这条支线的信号很明确：**具身推理（ER）比动作模型（VLA）更快走向开发者**——因为 ER 不需要绑定具体机器人硬件，可以作为「物理世界推理 API」独立售卖（ER 2 定价 $2/M input tokens）。这是「云脑 + 本地反射」二段式架构在商业上的第一次实证。

### 8.3 Physical Intelligence π 系列：从动作底座到「可操控大脑」

π 系列是 2024 年以来迭代最密集、主线最清晰的系列之一，也最能体现「系列」的价值——它把 VLA 的四个核心矛盾**一个接一个地解决**：

| 时间 | 模型 | 解决的核心矛盾 |
|---|---|---|
| 2024.10 | **π0** | PaliGemma 3B + flow matching，50 Hz，7 平台 68 任务，解决「连续控制 vs 离散 token」 |
| 2025.1 | **π0-FAST** | FAST 动作分词（DCT + BPE），动作 token 压缩约 10×，解决「动作 token 过长」 |
| 2025.2 | **Hi Robot** | 分层交互式系统，解决「开放式长指令跟随」 |
| 2025.4 | **π0.5** | 异构协同训练 + 知识隔离（KI），解决「开放世界泛化 vs 语义知识保持」 |
| 2025.5 | **π0.5-KI** | Knowledge-Insulated VLA，把动作专家「嫁接」到 VLM 而不侵蚀其预训练语义 |
| 2025.11 | **π0.6 / π\*0.6** | Gemma3 4B + 860M Action Expert，引入 **RECAP**（优势条件策略 + 纠错强化学习），解决「离线模仿 vs 真实部署可靠性」 |
| 2026.4 | **π0.7** | 多模态可操控条件（子目标图 / 元数据 / 控制模式），涌现**组合泛化**，被业内类比为机器人领域的「GPT-2 时刻」 |

这条链与 LLM 的「预训练 → 指令微调 → RLHF → 可操控对齐」演进高度同构。**前文第 2.1 节只写到 π0 / π0.5，实际上 π 系列已经走到 π0.7**——这提示我们在跟踪一个系列时，单看某一代很容易误判它的「终点」。π0 的 flow matching 是起点，不是终点；π0.7 的「可操控 + 组合泛化」才是这条线真正想抵达的地方。

### 8.4 NVIDIA GR00T 系列：双系统人形基座的快速迭代

GR00T 系列（N1 起）是「双系统架构」（前文 2.4）的最完整工业实践，且是唯一一个**把「合成数据引擎」作为系列主线**来迭代的：

| 时间 | 模型 | 关键变化 |
|---|---|---|
| 2025.3 | **GR00T N1** | Eagle-2 双系统（System 2 VLM 规划 + System 1 DiT 动作），2B，开放（Apache 2.0），仅 10% 真实数据即可达 42.6% 成功率 |
| 2025.5 | **GR00T N1.5** | 用 **GR00T-Dreams** 蓝图生成合成数据，**36 小时**完成整个开发周期（人工采集需约 3 个月），Language Table 52.8%→93.2% |
| 2025.9 | **GR00T N1.6** | **首次不用第三方 VLM**——改用内部 Cosmos-Reason-2B 作 System 2，DiT 从 16 层翻倍到 32 层，动作改为 state-relative |
| 2026.4 | **GR00T N1.7**（Early Access） | 升级 Cosmos-Reason2-2B，加入 **EgoScale 预训练**（20,854 小时人类第一视角视频），报告**首个机器人灵巧度 scaling law** |

N1.7 的「EgoScale」与 VITRA（前文 3.4）殊途同归——都试图把海量人类第一视角视频变成 VLA 的预训练燃料，且 N1.7 通过「相对末端执行器动作空间」让人类视频和机器人本体共享同一动作空间。**这说明「人类视频作为预训练数据」已经从学术探索（VITRA）上升为头部厂商的标准操作（NVIDIA）**。

### 8.5 开源 VLA 双雄：OpenVLA 与 Octo

这条线由 Finn / Levine 团队（PI 联合创始人）主导，是「闭源 RT 系列」的**开源镜像**，也是整个 VLA 社区可复现性的基石：

- **Octo**（2024.5，RSS 2024）：UC Berkeley + Stanford + CMU + DeepMind 联合，**首个完全开源**的通用机器人策略，在 OXE 800K 轨迹上预训练，提供 Octo-Small（27M）/ Octo-Base（93M）两个 checkpoint。它的贡献是「**输入 token 化器 + Transformer 骨干 + 扩散读出头**」的三段式设计——把「任务定义 + 观察」统一成 token，再用一个小规模扩散模块输出动作。前文 2.1.2 说的「扩散动作头」就是它开创的。
- **OpenVLA**（2024.6）：Prismatic-7B 骨干，OXE 970K 轨迹，256 bin 离散动作。它是第一个**性能对标闭源 RT-2-X（55B）的开源 7B VLA**，LoRA 微调只需 1.4% 参数、单卡 A100，把 VLA 从「大厂专属」拉到「实验室可复现」。
- **OpenVLA-OFT**（2025.2，arXiv:2502.19645）：OpenVLA 的官方续作，把「自回归离散解码」换成「**并行解码 + 连续动作表示 + L1 回归**」，推理加速 **26×**，LIBERO 平均成功率从 76.5% 提到 **97.1%**。**这正是前文 7.1 说的「离散 → 连续」在开源线上的落地**——OpenVLA 和 OpenVLA-OFT 之间的差异，浓缩了整个 VLA 领域 2024→2025 的动作表示革命。

> 注：Octo 与 SpatialVLA 是两项独立工作，SpatialVLA（上海 AI Lab）探索「空间表征增强 VLA」，不属于 Octo 系列。

### 8.6 世界模型 / WAM 系列：从数据引擎到统一底座

这条线横跨多个机构，但沿一条清晰的主轴——**世界模型在 VLA 里的角色不断「升格」**：

| 时间      | 工作                      | 世界模型的角色                                                 |
| ------- | ----------------------- | ------------------------------------------------------- |
| 2026    | **GigaBrain-0**（前文 3.3） | **数据引擎**：五种方式为 VLA 生成训练数据                               |
| 2026    | **DreamZero**（前文 3.4）   | **动作策略本体**：视频扩散联合预测「未来视频 + 动作」                          |
| 2025.12 | **Motus**（前文 7.2）       | **统一具身底座**：MoT 架构统一 VLA / WM / VGM / IDM / 联合预测         |
| 2026.4  | **MotuBrain**           | Motus 的工业版，RoboTwin 2.0 clean 95.8%，54.4× 加速，11 Hz 实时部署 |

GigaBrain-0（数据引擎）→ DreamZero（策略本体）→ Motus（统一底座）→ MotuBrain（工业落地），这四步恰好是**世界模型在 VLA 中「由辅入主」的完整升格路径**。前文第 7.2 节把 Motus 作为孤立的新范式来讲，但放进系列后会发现：它是 WAM 路线从「工具」变「本体」的临界点，而非孤例。

### 8.7 离散扩散原生 VLA 系列：动作表示的第二次革命

这是 2026 年最新、也最「抱团」的一个系列——多支团队几乎同时转向「离散扩散」：

- **MMaDA-VLA**（2026.3，西湖大学等）：首个原生预训练的大离散扩散 VLA，统一离散 token 空间 + 掩码去噪（前文 7.1.2）。
- **Discrete Diffusion VLA**（ICML 2026，SJTU）：自适应解码顺序，几乎不损失 VLM 先验。
- **UD-VLA / Unified Diffusion VLA**（2025.11）：理解、生成、动作放进同一条联合去噪轨迹。
- **LLaDA-VLA / MemoryVLA / VLA-Adapter / OpenVLA-OFT**：这一波「扩散化 + 动作块 + 高效适配」的标准 SOTA 配方库。

这个系列的集体转向，本身就是对前文第 2.1 节「连续 flow matching 是终点」判断的**系统性证伪**——当多个独立团队在同一时间不约而同地回到「离散」，说明连续流范式确实存在结构性短板（架构冗余、chunk 内误差累积、缺乏环境动态内生建模），而非个别工作的偏好。

### 8.8 数据系列：Open X-Embodiment 的血脉延续

数据的演化同样有「系列」——前文 3.1 的四代数据集，本质上是一个**不断被继承、扩充、标准化**的连续谱系：

| 时间 | 数据集 | 与前代的继承关系 |
|---|---|---|
| 2022 | RT-1 数据 | 13 万轨迹，单一本体，起点 |
| 2023 | **Open X-Embodiment（OXE）** | 21 机构联合，100 万+ 轨迹 / 22 本体 / 527 技能，**把 RT-1 的采集范式推向跨机构** |
| 2024 | **DROID** | 76K 轨迹，Franka 单臂标准化，**反拨 OXE 的异构性**，用一致性换质量 |
| 2024 | **AgiBot World** | 100 万+ 轨迹 / 217 任务，**在 DROID 的标准化基础上重新拉大规模**，扩展到双臂/工具/长程 |

OXE 是这个系列的关键节点：它不只是一个数据集，而是一个**「跨本体数据共享」的标准协议**——RT-X、OpenVLA、Octo、π0 全都建立在 OXE 之上。前文 3.1 把四代数据作为「规模 vs 一致性」的拉锯来写，补上「系列」视角后会发现：**每一代都不是替代前代，而是在前代的基础上修正一个缺陷**（OXE 修正「单一本体」、DROID 修正「异构」、AgiBot World 修正「规模不足」）。这正是「数据系列」与「模型系列」同构的地方——都是螺旋上升，而非线性替换。

### 8.9 系列视角的方法论启示

把前七章的「问题主线」和本章的「系列主线」叠加，会得到一个更完整的读法：

1. **单篇论文是「快照」，系列才是「轨迹」**。只看 RT-2 会以为「离散 token 是终点」，只有看到 OpenVLA-OFT / π0.7 / MMaDA-VLA 才知道那只是起点。
2. **系列内部的代际差异，往往比跨系列的方法差异更能揭示技术方向**。例如 OpenVLA → OpenVLA-OFT 的「离散 → 连续」，比 OpenVLA 和某个其他模型的架构差异，更准确地标定了 2024→2025 的动作表示革命。
3. **人员流动把系列串成了一张网**。RT → π → OpenVLA/Octo 不是三条平行线，而是同一批人（Finn / Levine / Hausman / Ichter）在不同阶段、不同体制下的连续探索。
4. **跟踪一个系列，要看它的「主线矛盾」是否转移**。π 系列从「动作表示」转向「可操控 + 组合泛化」、GR00T 系列从「双系统」转向「合成数据 + 人类视频」，这些主线转移本身，就是领域下一个风向的提前信号。
